## Use Cases with Insight 360

### 1. Forecast Analysis
**Goal:** Synthesize pipeline data with historical patterns for accurate forecasting

**Workflow:**
1. Pull current pipeline snapshot
2. Analyze historical conversion rates by stage
3. Use **Research Assistant** for pattern identification
4. Adjust forecast based on insights

**Agents Used:** Research Assistant
**Gap Identified:** Forecast Analyst Agent for predictive modeling

---

### 2. Deal Strategy
**Goal:** Analyze complex deals and recommend next actions

**Workflow:**
1. Document deal context (stakeholders, timeline, objections)
2. Use **Strategic Advisor** for deal strategy
3. Identify risks and mitigation approaches
4. Map buying committee and influence

**Agents Used:** Strategic Advisor
**Gap Identified:** Deal Strategy Agent for complex deal navigation

---

### 3. Win/Loss Analysis
**Goal:** Deep dive on closed deals to identify patterns

**Workflow:**
1. Gather win/loss data and notes
2. Use **Research Assistant** to identify patterns
3. Extract actionable insights for team
4. Update playbooks based on findings

**Agents Used:** Research Assistant
**Gap Identified:** Win/Loss Analyst Agent for systematic analysis

---

### 4. Competitive Battlecards
**Goal:** Generate and update competitive positioning

**Workflow:**
1. Identify key competitors
2. Use **Research Assistant** (with search) for current intel
3. Create battlecard with positioning and objection handling
4. Keep updated with market changes

**Agents Used:** Research Assistant
**Gap Identified:** Competitive Intelligence Agent for ongoing updates

---

### 5. Sales Coaching Prep
**Goal:** Prepare for 1:1s with rep performance insights

**Workflow:**
1. Gather rep metrics and pipeline data
2. Use **Meeting Prep** for coaching agenda
3. Identify specific development areas
4. Prepare coaching questions and feedback

**Agents Used:** Meeting Prep
**Coverage:** Partially covered

---

### 6. Territory Planning
**Goal:** Optimize territory assignments for coverage

**Workflow:**
1. Define territory criteria and data
2. Use **Research Assistant** for analysis
3. Balance workload and opportunity

**Agents Used:** Research Assistant
**Gap Identified:** Territory Optimizer Agent for data-driven assignments

---

### 7. Quarterly Business Review (QBR)
**Goal:** Generate QBR presentation materials

**Workflow:**
1. Gather quarterly performance data
2. Use **Meeting Prep** for structure
3. Use **Writing Coach** for narrative
4. Identify key wins, losses, and learnings

**Agents Used:** Meeting Prep, Writing Coach
**Gap Identified:** QBR Generator Agent for standardized reviews

## Quick Start Prompts

### Forecast Analysis
```
Analyze our current pipeline for forecast accuracy:
- Stage conversion rates vs. historical
- Risk deals (stalled, pushed, champion change)
- Commit vs. best case recommendations
- Assumptions to validate with reps
```

### Deal Strategy
```
Help me strategize this deal:
Account: [COMPANY]
Current stage: [STAGE]
Key stakeholders: [NAMES/ROLES]
Main objections: [OBJECTIONS]
Competition: [COMPETITORS]

Recommend:
1. Power map and influence strategy
2. Next best actions
3. Risk mitigation
4. Win themes to emphasize
```

### Win/Loss Analysis
```
Analyze our Q4 wins and losses:
Wins: [COUNT]
Losses: [COUNT]
Provide:
- Common win themes
- Primary loss reasons
- Competitive patterns
- Recommendations for Q1
```

### Sales Coaching
```
Prepare coaching for my 1:1 with [REP NAME]:
Quota attainment: [%]
Pipeline coverage: [X]
Recent wins: [COUNT]
Recent losses: [COUNT]

Identify:
- Strengths to recognize
- Development areas
- Specific deals to review
- Coaching questions to ask
```

### QBR Preparation
```
Generate Q4 QBR content:
- Revenue vs. target
- Win rate trend
- Key wins and logos
- Competitive landscape shifts
- Top deals won and lessons learned
- Pipeline health for Q1
- Resource/support asks
```
