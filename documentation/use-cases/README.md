## How to Use These Documents

### For New Users
1. Find your role or closest match in the index
2. Review the responsibilities and pain points
3. Try the "Quick Start Prompts" with existing agents
4. Follow the workflow recommendations

### For Administrators
1. Use the [00-overview.md](00-overview.md) for agent gap analysis
2. Prioritize new agent development based on coverage gaps
3. Create role-specific context assets as recommended
4. Update documents as new agents are deployed

### For Sales/Demos
1. Select relevant role documents for prospect's team
2. Use pain points to guide discovery conversations
3. Demo specific use cases that match their priorities
4. Reference agent recommendations for expansion opportunities

## Document Structure

Each role document follows this structure:

1. **Role Overview** - North star, key metrics, persona reference
2. **Job Description** - Core responsibilities table
3. **Pain Points** - Problems and business impact
4. **Use Cases** - Detailed workflows with agents
5. **Agent Configuration** - Recommended setup
6. **Quick Start Prompts** - Copy-paste templates
7. **Workflows** - Role-specific processes
