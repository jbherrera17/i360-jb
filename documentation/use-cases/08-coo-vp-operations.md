## Pain Points

| Pain Point | Description | Business Impact |
|------------|-------------|-----------------|
| **Change Fatigue** | Teams resistant to new processes | Slow adoption, failed initiatives |
| **Data Silos** | Information trapped in departments | Blind spots, poor decisions |
| **Lean vs. Innovation** | Cutting costs vs. investing in future | Difficult trade-offs |
| **Vendor Management** | Multiple suppliers, variable performance | Quality risk, complexity |
| **Scale Challenges** | What worked small breaks at scale | Growing pains, inefficiency |

## Use Cases with Insight 360

### 1. Process Documentation
**Goal:** Document and standardize operational processes

**Workflow:**
1. Interview process owners and observe workflows
2. Map current state process
3. Use **Writing Coach** for clear documentation
4. Include exceptions and decision points

**Agents Used:** Writing Coach
**Gap Identified:** Process Documenter Agent for systematic process capture

---

### 2. Vendor Evaluation
**Goal:** Compare vendors against evaluation criteria

**Workflow:**
1. Define evaluation criteria and weights
2. Gather vendor information and proposals
3. Use **Research Assistant** for analysis
4. Score and rank vendors

**Agents Used:** Research Assistant
**Gap Identified:** Vendor Evaluator Agent for structured comparisons

---

### 3. Operations Dashboard Narrative
**Goal:** Explain KPI movements and trends

**Workflow:**
1. Review operations dashboard data
2. Identify significant changes
3. Use **Writing Coach** for narrative explanation
4. Provide context and recommendations

**Agents Used:** Writing Coach
**Gap Identified:** Ops Analyst Agent for operations-specific insights

---

### 4. Continuous Improvement Ideas
**Goal:** Generate kaizen/improvement suggestions

**Workflow:**
1. Define area or process to improve
2. Gather current performance data
3. Use **First Principles Thinker** for improvement ideas
4. Prioritize by impact and effort

**Agents Used:** First Principles Thinker
**Coverage:** Partially covered

---

### 5. Risk Identification
**Goal:** Identify operational risks in processes

**Workflow:**
1. Map critical processes and dependencies
2. Use **Risk Sentinel** for risk identification
3. Assess probability and impact
4. Develop mitigation plans

**Agents Used:** Risk Sentinel
**Coverage:** Fully covered

---

### 6. Change Management Communication
**Goal:** Draft change announcements and training materials

**Workflow:**
1. Define the change and audience
2. Identify concerns and benefits by stakeholder
3. Use **Writing Coach** for communications
4. Create supporting materials

**Agents Used:** Writing Coach
**Coverage:** Fully covered

---

### 7. Capacity Planning
**Goal:** Model capacity scenarios for planning

**Workflow:**
1. Define capacity parameters
2. Input current utilization and constraints
3. Use **Research Assistant** for scenario modeling
4. Identify bottlenecks and expansion needs

**Agents Used:** Research Assistant
**Gap Identified:** Capacity Planner Agent for operational modeling

## Quick Start Prompts

### Process Documentation
```
Document this operational process:
Process name: [NAME]
Objective: [PURPOSE]
Owner: [ROLE]
Current steps: [HIGH-LEVEL STEPS]

Include:
- Step-by-step procedures
- Decision points and criteria
- Roles and responsibilities
- Exception handling
- Quality checkpoints
```

### Vendor Evaluation
```
Evaluate these vendors for [CATEGORY]:
Vendors: [VENDOR 1], [VENDOR 2], [VENDOR 3]
Evaluation criteria:
1. [CRITERION 1] - Weight: [%]
2. [CRITERION 2] - Weight: [%]
3. [CRITERION 3] - Weight: [%]

Provide:
- Scored comparison matrix
- Pros and cons for each
- Risk assessment
- Recommendation with rationale
```

### Operations Narrative
```
Explain these operational KPI changes:
Metric: [METRIC]
Previous: [VALUE]
Current: [VALUE]
Trend: [DIRECTION]

Provide:
- Root cause analysis
- Contributing factors
- Comparative context
- Recommended actions
```

### Continuous Improvement
```
Suggest improvements for this process:
Process: [NAME]
Current performance: [METRICS]
Pain points: [LIST]
Constraints: [LIST]

Provide:
- Quick wins (low effort, high impact)
- Medium-term improvements
- Strategic changes
- Implementation prioritization
```

### Change Communication
```
Draft change communication for:
Change: [DESCRIPTION]
Audience: [TEAMS/ROLES]
Timeline: [WHEN]
Impact: [WHAT CHANGES]

Include:
- Announcement email
- FAQ document
- Training outline
- Feedback mechanism
```

### Capacity Planning
```
Model capacity for [AREA]:
Current capacity: [METRICS]
Current utilization: [%]
Growth projection: [%]
Constraints: [LIST]

Provide:
- Capacity analysis
- Scenario modeling (base, growth, high growth)
- Bottleneck identification
- Investment recommendations
```
