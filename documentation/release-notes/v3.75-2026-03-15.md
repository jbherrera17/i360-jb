## New Features

### Embeddable Chat Widget

Public-facing chat widget that can be embedded on any external website via a single script tag. Security-isolated from internal support tools (no access to refund, tier_change, or customer_lookup).

**Embed code:**
```html
<script src="https://your-domain/js/chat-widget.js"
        data-widget-id="WIDGET_UUID"
        data-token="HMAC_TOKEN"></script>
```

### Pre-Chat Configuration

Four modes control what visitors see before chatting:

| Mode | Description |
|------|-------------|
| Lead Capture | Email required before chat (default for Annie) |
| Open Chat | No form — immediate chat for support use cases |
| Optional Info | Form shown but skippable |
| Custom | Admin configures each field individually |

### PII Redaction Pipeline

All visitor messages pass through 10-pattern PII detection before database storage:
- Email, phone, SSN, date of birth, credit card, medical record number, address, ZIP code, insurance ID
- Fail-safe: if redaction errors, message is NOT stored
- Pre-chat fields (email, name) stored separately from conversation content

### LLM Cost Optimization

- Intent classification routes simple FAQs to Haiku (~15x cheaper than Sonnet)
- Conversation summarization after turn 3 reduces token replay
- Soft cap at usage ceiling — auto-degrades to Haiku-only, never kills widget
- Daily spend caps per tier ($5/$25/$100)

### Google Sheets Data Connector

Sync spreadsheet data to context assets on a configurable schedule (default 15 min). Data sanitized for injection patterns on import. Admin panel in Support Settings > Data Sources tab.

### Calendly Integration

New integration provider supporting OAuth and Personal Access Token. Per-procedure embed URL mapping. Admin panel in Support Settings > Integrations tab.

### Conversation Review Dashboard

New page at `/conversation-review.html`:
- Two-panel layout: conversation list + transcript viewer
- Full-text search across message content
- Filter by status, sentiment, widget, date range
- Multi-select conversations for bulk export
- Export to CSV, JSON, or Context Asset (knowledge feedback loop)
- Internal notes system (not visible to visitors)

### Privacy & Compliance Admin

New tab in Support Settings:
- Editable privacy policy with default template and preview
- Consent text editor
- AI disclosure text customization
- Medical disclaimer editor
- Data retention period selector (30-365 days)

### Demo Environment

6-page medical practice simulation at `/demo/`:
- Homepage with procedure cards
- 5 procedure pages (facelift, rhinoplasty, blepharoplasty, necklift, browlift)
- Annie widget embedded on facelift demo page
- No authentication required — suitable for client demonstrations
