**Release Date:** March 16, 2026
**Phase:** 77 — TL Page UX Redesign
**Previous:** v3.76 (TL Content Creation Workflow)

## Highlights

- Thought Leadership page restructured from 7-section scrolling dashboard to two-mode workflow cockpit
- "This Week" mode (default): auto-populated content card, one-click generate with live progress, inline results with Preview/Edit/Regen, publish targets, upcoming/recent lists
- "Settings" mode (gear icon): 5-tab configuration (Position, Pillars, Calendar, Visibility, Publishing & Integrations)
- Content review: navigate to any past week and see article, image, and LinkedIn posts in one place

- Full accessibility: aria-live for generation progress, tablist/tab/tabpanel for settings, focus management on mode switch

## New Features

### Two-Mode Interface

The page now separates weekly execution (95% of visits) from configuration (5% of visits):

| Mode | Purpose | Access |
|------|---------|--------|
| **This Week** | Generate and publish content | Default on page load |
| **Settings** | Configure positioning, pillars, calendar, integrations | Gear icon in header |

### "This Week" Mode Components

| Component | Description |
|-----------|-------------|
| **Content Card** | Auto-populated from editorial calendar for current ISO week. Shows title, pillar badge (left-border accent in pillar color), format, theme, cornerstone reference, week position. Empty state with link to Calendar Settings |
| **Generate Card** | Ambient pre-flight dots (auto-loaded on page open), 5-step pipeline with 4 visual states (empty/active/done/failed), elapsed time per step, "Generate This Week's Package" CTA, ~90 second estimate |
| **Results Card** | Per-output rows: Article (word count + Preview/Edit), AI Version (Preview), Image (thumbnail + Preview/Regen), LinkedIn (post count + Preview). Inline quality checklist. Publish targets with checkboxes. Publish Package button |
| **Upcoming** | Next 2-3 weeks as compact clickable rows with format badges and dates |
| **Recent** | Last 8 weeks with status badges (published/review/planned) and streak counter |

### Content Review on Week Navigation

Clicking any week in Upcoming or Recent loads that week's content:
- Content Card updates with the selected week's topic and metadata
- Header updates to show the selected week number and date range
- If content was previously generated, Results Card auto-populates with stored article, image, and LinkedIn posts
- Generate button changes to "Regenerate Package"
- Users can Preview, Edit, or Regen from the same interface

This enables reviewing article, header image, and marketing posts all in one place.

### Settings Mode (5 Tabs)

| Tab | Content |
|-----|---------|
| **Position** | Core thesis, atomic claim, Run Niche Discovery / Edit Position buttons |
| **Pillars** | Content pillar cards grid with add/edit/delete |
| **Calendar** | Full month calendar grid with Notion sync and entry management |
| **Visibility** | AI visibility score circle and Check Visibility research button |
| **Publishing & Integrations** | Default publish targets, LLM model/Voice DNA/ICP/Business Profile selection with Save as defaults, scheduling |

### Publishing Streak

The Recent section now shows a streak counter (e.g., "10 weeks in a row") calculated from consecutive published weeks. Motivates consistency without gamification.

## UX Improvements

### Design Decisions (Taylor, UI/UX Manager)

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Pillar accent | Left border (4px solid, pillar color) | Matches existing border-left patterns, subtle but clear |
| Article preview | Rendered markdown with View Source toggle | Users see final form first (workflow-first UX) |
| Week navigation | Replace Content Card in-place | Simplest interaction, matches smart context principle |
| Streak visualization | Simple counter + status dots | Professional audience, not gamification |
| Settings transition | Instant switch with 150ms opacity fade | Deliberate but not slow |

### Workflow-First Principles Applied

All 12 UX principles from `Workflow-UX-Design-Principles.md` are implemented:
1. Primary Action Prominence — Generate CTA is the largest, most visible element
2. Configuration vs Execution Separation — Settings behind gear icon
3. Smart Context — Content Card auto-populated from calendar
4. Progressive Disclosure — Details in modals, summaries on page
5. Ambient Status — Pre-flight dots load automatically
6. One-Click Workflows — Single button generates full package
7. Results Inline — No navigation away to see outputs
8. Streak Visibility — Publishing streak counter
9. Graceful Degradation — Failed steps don't block others
10. Pre-flight Before Commitment — Integration checks before generation
11. Undo/Retry Granularity — Per-step retry buttons
12. Time Expectation Setting — Progress with elapsed time and estimate

## Security

### XSS Mitigation in Markdown Renderer

Added sanitization to `renderPackageMarkdown()` before markdown processing:
- Strip `<script>` tags and content
- Strip dangerous elements (`<iframe>`, `<object>`, `<embed>`, `<form>`, `<input>`, `<button>`)
- Neutralize inline event handlers (`onclick=`, `onload=`, etc.)

Risk level: Medium (LLM-generated content, not direct user input). Mitigated.
