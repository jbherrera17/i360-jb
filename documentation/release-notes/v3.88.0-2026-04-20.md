# v3.88.0 — REQ-002a: Chat Support System Consolidation

**Release date:** 2026-04-20
**Tier:** 2 (Full Launch Readiness — Jordan GO pending)
**Closes MVP items:** #6, #7, #8 (from `MVP-OPEN-ITEMS.md`)

## Summary

Consolidated the Support settings UI from 7 tabs to 4, renamed the two support pages to reflect their actual purpose, and added Playwright e2e coverage for Annie's Vimeo, YouTube, and Calendly card rendering — the two Phase C UX paths that were previously untested.

## Changes

### Page renames
- `support-settings.html` → **"Chat Support System Settings"**
- `support-dashboard.html` → **"Support System Dashboard"**
- Administrator dashboard tiles updated to match

### Settings page restructure (7 → 4 tabs)
- **Widget Config** — absorbed the old Chat Widgets tab; now the single source of truth for per-widget config. The old local-only Widget Config tab (never wrote to DB) has been deleted.
- **Policies** — unchanged
- **Privacy & Compliance** — unchanged
- **Integrations** — absorbed Connections (Stripe, Slack) and Data Sources (Google Sheets) as sections within one tab. Scheduling (Calendly) stays as a section here.

### New capability
- `is_active` toggle on per-widget config, plumbed through `editWidget` and `saveWidgetDetail`

### Quality / hygiene
- `support-dashboard.html` auth migrated to `authFetch()` + `auth-fetch-loader.js` (Phase 82 gap closed; manual `getHeaders()` deleted)
- `switchTab()` lazy-loads Privacy + Integrations on first open (reduces initial load API calls from 3 to 1)
- Dead code purged: `widgetConfig` state object, `saveWidgetConfig`, `collectFormData`, `renderFields/addField/removeField`, `renderDomains/addDomain/removeDomain`, `updateColorSwatch`, `updateAvatarPreview`

### Documentation
- New user guides: `support-settings-user-guide.md`, `support-system-dashboard-user-guide.md`
- Help registry + docs whitelist (`server/routes/docs.js` ALLOWED_DOCS) updated
- MVP-OPEN-ITEMS.md items #6, #7, #8 marked complete

### Testing
- `__tests__/e2e-ui/annie-video-cards.spec.js` — 5 tests (Vimeo, YouTube, youtu.be short URL, bare-link fallback)
- `__tests__/e2e-ui/annie-calendly.spec.js` — 7 tests (desktop structure, href target, noopener, multi-card, mobile visibility, tap target, no horizontal scroll, readability)
- Supporting fixture: `public/test-widget-fixture.html` (same-origin harness for widget mount — avoids Cross-Origin-Resource-Policy block)
- 12/12 Playwright specs green (~4.7s)
