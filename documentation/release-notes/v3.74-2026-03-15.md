## Highlights

## New Features

### Pre-Flight Integration Checks
Before starting any multi-step workflow, the system now verifies all downstream integrations and presents a status dashboard to the user. Each integration shows green (ready), yellow (degraded), or red (unavailable).

| Integration | What's Checked |
|-------------|---------------|
| Image Generation | API key valid, preferred model available, circuit breaker status |
| Notion | API key set, Content Calendar database accessible |
| Social Media | Postiz configured, connected platforms listed |
| Substack (beta) | Credentials exist, cookies not expired |
| LinkedIn | Token validity, auto-refresh capability |
| Blog | Always ready (local) |

**Endpoint:** `GET /api/thought-leadership/preflight`

### Automatic Image Generation
Article generation (`/generate/article`) now automatically produces a header image alongside the article text. Users can opt out with `generate_image: false`.

### Multi-Model Image Support
| Model | Status | Default Size |
|-------|--------|-------------|
| GPT Image 1.5 | **Default** | 1536x1024 |
| DALL-E 3 | Deprecated May 2026 | 1792x1024 |
| DALL-E 2 | Legacy | 1024x1024 |

User preference stored in TL profile. Model-specific quality mapping normalizes across APIs.

### Public Blog Publishing
New public route at `/blog/:slug` serves SEO-optimized article pages:
- Header image with Open Graph and Twitter Card meta tags
- Sanitized markdown rendering (marked + sanitize-html for XSS protection)
- Previous/next article navigation
- Atomic view count tracking
- Blog index at `/blog`

### Notion Full-Page Publishing
Creates a database entry in the Content Calendar with all properties + 4 toggle sections:
1. **Image** — header image (external URL from Supabase Storage)
2. **Article** — full human-readable article
3. **AI Article** — AI-optimized structured version
4. **Marketing** — LinkedIn posts with daily themes and schedule table

### Substack Publishing (Beta)
Publishes articles to Substack via reverse-engineered API endpoints:
- Cookie-based authentication (encrypted with AES-256-GCM)
- Three-step process: create draft, prepublish, publish
- Markdown-to-Substack ProseMirror format conversion

### Unified Publish Package
Single endpoint (`/publish/package`) orchestrates publishing to all selected targets:
- Partial success handling (some targets succeed, others can fail independently)
- Per-target results with links and error details

## Bug Fixes

| Fix | Before | After |
|-----|--------|-------|
| Notion `Status` property | Set as `select` type (API rejected it) | Correctly set as `status` type |
| Notion `Goal` property | Set as `rich_text` (wrong data type) | Correctly set as `select` type |
| Notion `Status` filter | Used `select` filter in queries | Uses `status` filter |
| Missing Notion properties | `Month/YR`, `Quarter`, `URL` never set | All three now populated correctly |
| Package image errors | Silently swallowed into `errors[]` array | Surfaced to user with `partial: true` flag and retry hints |
| OAuth alert dialogs | Used `alert()` for LinkedIn OAuth status | Uses `showToast()` |

## Security

| ID | Finding | Mitigation |
|----|---------|-----------|
| SEC-001 | Blog XSS via markdown rendering | `marked` + `sanitize-html` strips all scripts/events |
| SEC-002 | Substack cookie storage | Encrypted with AES-256-GCM using `TOKEN_ENCRYPTION_KEY` |
| SEC-004 | Blog slug enumeration | All public queries filter `is_published = TRUE`; 404 for unpublished |
