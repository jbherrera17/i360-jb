# Insight 360 v3.81 Release Notes

**Release Date:** March 19, 2026
**Phase:** 81 — Infrastructure Integrity Remediation
**Previous:** v3.80.1 (LLM Health Check Billing Error Fix)

---

## Highlights

- All 5 core route files now enforce `requireModule()` middleware for tier/role gating
- Every single-record endpoint (GET/PUT/DELETE /:id) verifies org ownership before returning data
- 39 raw `fetch()` calls replaced with `authFetch()` across agents, skills, actions, and workflows pages
- `skill_summary` view updated with `org_id` and `module_id` columns
- Workflow executions now carry `org_id` for proper scoping
- System resources (agents, skills, actions, workflows) backfilled with Synergi org_id
- Phase 50 `skill_departments` junction table and `filterByBusinessRole()` now wired into skills list

---

## What Changed

### Module Gating

Added `requireModule()` from `moduleAccess.js` to all 5 route files:

| Route | Module ID | Notes |
|-------|-----------|-------|
| `agents.js` | `agents` | New middleware + `checkResourceLimit` import |
| `skills.js` | `skills` | New middleware |
| `actions.js` | `actions` | Replaced custom inline middleware with standard `requireModule` |
| `parthenon.js` | `parthenon` | Was completely unprotected before Phase 81 |
| `workflows.js` | `workflows` | Converted to factory pattern; added `checkResourceLimit('workflows')` on POST |

### Ownership & Org Checks

Every GET/PUT/DELETE /:id endpoint now checks access before returning data:

| Route | Endpoints Protected |
|-------|-------------------|
| Agents | GET /:id, GET /stats, GET /suites, POST /:id/duplicate, GET /:id/executions |
| Skills | GET /:id, PUT /:id, DELETE /:id, POST /:id/duplicate, GET /categories, GET /stats |
| Actions | GET /:id, GET /featured, POST /from-template, PUT /external-ai/:id, DELETE /external-ai/:id |
| Parthenon | PUT/DELETE /departments/:id, PUT /roles/:id, PUT /okrs/:id, PUT /processes/:id, GET /overview, POST /seed-defaults |
| Workflows | GET /:id, POST/PUT/DELETE /:id/steps/*, PUT /:id/steps/reorder |
