# Insight 360 v3.82 Release Notes

**Release Date:** March 19, 2026
**Phase:** 82 — Platform-Wide Multi-Tenant Data Isolation
**Previous:** v3.81 (Infrastructure Integrity Remediation)

---

## Highlights

- Every API call now carries authenticated user identity and organization context automatically
- Cross-organization data leakage eliminated across all routes and pages
- ESLint prevention rule structurally blocks this class of vulnerability from recurring
- Setup wizard improvements for new organization onboarding

---

## Problem

A platform-wide audit revealed systemic multi-tenant data isolation failures:

| Issue | Scope | Severity |
|-------|-------|----------|
| Raw `fetch()` calls with no auth token | 559 calls across 66 files | Critical |
| Backend routes returning all orgs' data when orgId is null | 15+ endpoints across 6 route files | Critical |
| `x-org-id` header not validated against user's org membership | All routes accepting the header | Critical |
| `authFetch` not attaching `x-org-id` header | Every API call | High |
| `auth-fetch.js` loading asynchronously (race condition) | All pages using navigation.js | High |
| Setup wizard admin not assigned executive role/department | New org onboarding | Medium |

This was the third recurrence of this issue class. Prior fixes were localized — this phase addresses it structurally.

## Fix

### Phase 0: Foundation Infrastructure

| Component | File | Purpose |
|-----------|------|---------|
| `requireOrgContext` middleware | `server/middleware/orgContext.js` | Validates `x-org-id` against `organization_members`. Rejects unauthorized org access with 403 |
| `scopeToOrg()` helper | `server/utils/orgScope.js` | Applies org filter to queries. **Throws on null orgId** — eliminates "return everything" fallback |
| `getOrgDepartmentIds()` helper | `server/utils/orgScope.js` | Parthenon pattern: scopes through `department_id` → `departments.org_id` |
| `authFetch` x-org-id | `public/js/auth-fetch.js` | Now reads `insight360_org_id` from localStorage and attaches as `x-org-id` header |
| Synchronous loader | `public/js/auth-fetch-loader.js` | Ensures `authFetch` is defined before `DOMContentLoaded` fires |
| Login org storage | `public/login.html` | Invite acceptance path now stores org_id (was missing) |
| CLAUDE.md rules | `CLAUDE.md` | Mandatory multi-tenant scoping rules for all new code |

### Phase 1: Critical Route Hardening

| Route File | Endpoints Fixed | Fix Description |
|-----------|----------------|-----------------|
| `execute120.js` | 15+ endpoints | `requireOrgContext` middleware, all 6 helper functions scoped, ownership checks on departments and executions, strategic overview scoped to org departments |
| `conversations.js` | `admin/all`, `admin/stats`, `admin/:id` | Org scoping on all admin queries, platform admin bypass |
| `departments.js` | `GET /`, `GET /:id` | Eliminated "return all non-null" fallback, added ownership check |
| `parthenon.js` | `GET /departments/:id` | Org ownership validation |

### Phase 2: Agent Route Hardening

| Route File | Endpoints Fixed | Fix Description |
|-----------|----------------|-----------------|
| `agents.js` | `/:id/stats`, `/:id/executions/:execId`, `/seed-suites`, all context mapping CRUD | `verifyAgentOrgOwnership` helper, ownership checks before returning or mutating data |

## Anti-Patterns Eliminated

| Before (DO NOT USE) | After (Required) |
|---------------------|------------------|
| `fetch('/api/agents')` | `authFetch('/api/agents')` |
| `if (orgId) { query.eq('org_id', orgId) }` | `scopeToOrg(query, orgId)` |
| `if (orgId) { ... } else { query.not('org_id', 'is', null) }` | `scopeToOrg(query, orgId)` (throws on null) |
| `query.or(\`org_id.eq.${orgId},org_id.is.null\`)` | `scopeToOrg(query, orgId)` |
| No org check on `/:id` endpoints | `requireOrgContext` middleware + ownership verification |
