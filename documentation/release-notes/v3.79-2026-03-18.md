## Commit: Platform Admin Org Scope + Org Chart

**Hash:** `a42938f`

### Platform Admin Org Scope Selector

Added an organization dropdown to the context assets page, visible only to verified platform admins:

| Feature | Description |
|---------|-------------|
| Admin verification | Calls `/api/platform/admin/verify` on page load to check admin status |
| Org dropdown | Populated from `/api/organizations`, defaults to user's current org |
| All Organizations | Admin-only option to see assets across all orgs |
| Impersonation lock | During impersonation, dropdown locks to impersonated org (disabled) |
| Regular users | No change — org scoping via `currentOrgId` in localStorage as before |

**Frontend files:**

| File | Changes |
|------|---------|
| `public/context.html` | Added org scope selector row with `<select id="orgScopeFilter">` |
| `public/js/context.js` | Added `initOrgScope()`, state properties (`isPlatformAdmin`, `selectedOrgId`, `organizations`), org-aware `apiCall()` routing, ESLint globals |

**Backend files:**

| File | Changes |
|------|---------|
| `server/routes/context.js` | `GET /assets` handles `x-org-id: all` header; platform admins bypass visibility-based access control; regular user access control unchanged |
