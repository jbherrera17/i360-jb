## Patterns established (carry forward)

### Route file splits

Three runs in this session: `server/index.js`, `platformAdmin.js`,
`thought-leadership.js`. The recipe:

1. **Cut at section banners** (`// ===...===` blocks), NOT route-handler
   line numbers from grep. Banners give clean line boundaries; route grep
   gives starts of routes only.
2. **Pre-snapshot the route table** before deleting the original file.
   Walk the express router stack, dump `{method, path, handlers}` to a
   tmp file, sort. Source `dotenv.config()` first because some
   transitively-required services validate env at module load.
3. **Use a one-time splitter script**. Write to `scripts/_split-X.mjs`,
   slice by line ranges, wrap each slice in factory template, delete the
   script after the commit. Manual transcription of 14+ files is
   error-prone; the script is faster and exact.
4. **Coordinator pattern**: `index.js` mounts each sub-router in
   source-file order to preserve Express first-match priority.
   Closure-scoped middleware moves to `_shared.js` as a factory function
   that takes `supabase` and returns the middleware. Coordinator applies
   the factory once at the parent level; sub-routers can apply per-route
   write gates as needed.
5. **Hoist mid-file requires** to the top of consuming sub-files. Verify
   the hoisted services are side-effect-free at module load (just
   `require` + `const` + `module.exports`).
6. **Order-sensitive route pairs**: any `/foo/literal` that must register
   before `/foo/:id` must end up in the SAME sub-file, in the same
   order. The route-table diff catches violations.
7. **Verify with route-table diff**: post-split, walk the new entry point's
   stack, normalize sub-router regex prefix artifacts (paths come out as
   `/?(?=\\/|$)/foo`; strip the `/?(?=\\/|$)` prefix), sort, `diff -q`
   against the pre-snapshot. Must be byte-identical.
8. **Verify lint AND boot AND curl**: lint may flag unused imports the
   splitter generated optimistically — clean those up. Boot the dev
   server. Curl one endpoint per sub-file (expect 401 with auth required
   — proves route registered + auth gating intact).
