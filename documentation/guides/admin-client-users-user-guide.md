# Client Portal Users User Guide

**For:** Insight 360 Agency Administrators
**Last Updated:** January 2026

---

## Why Client Portal Users Is Important

The Client Portal Users page lets you manage self-service access for your clients. Invite client contacts to view their own reports, track portal engagement, and control who has access to client-specific content.

---

## What It Does

| Feature | Description |
|---------|-------------|
| **Invite Users** | Send magic link invitations to client contacts |
| **User Management** | View, search, and filter portal users |
| **Access Control** | Enable, disable, or remove user access |
| **Engagement Tracking** | See last login and report view activity |
| **Report Sharing** | Share reports with specific client users |

---

## Step by Step Use

### Inviting a Client User

1. Click **Invite User** in the page header
2. Select the **Client** this user belongs to
3. Enter the user's **Email Address**
4. Optionally enter their **Name**
5. Click **Send Invitation**
6. The user will receive a magic link via email to access the portal

### Managing Existing Users

1. View all users in the table showing:
   - Name and email
   - Associated client
   - Status (Active, Invited, Inactive, Removed)
   - Last login date
2. Use the search bar to find specific users
3. Filter by status or client using the dropdowns

### User Status Types

| Status | Meaning |
|--------|---------|
| **Invited** | Magic link sent, user hasn't logged in yet |
| **Active** | User has logged in and has access |
| **Inactive** | User hasn't logged in for 90+ days |
| **Removed** | Access has been revoked |

### Resending Invitations

1. Find the user with "Invited" status
2. Click the **Send** icon in the Actions column
3. A new magic link will be emailed to the user
4. Previous links are automatically invalidated

### Removing User Access

1. Click the **Remove** icon (person with X) for the user
2. Confirm the removal
3. User will no longer be able to access the portal
4. Their status changes to "Removed"

### Restoring User Access

1. Find the user with "Removed" status
2. Click the **Restore** icon (person with check)
3. The user will receive a new magic link
4. Their status changes back to "Active"

---

## Tips & Best Practices

- Send invitations during business hours for better response rates
- Follow up if a user hasn't accessed their invitation within 48 hours
- Remove access promptly when client relationships end
- Use descriptive names to easily identify users

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| User didn't receive email | Check spam folder; verify email address is correct |
| Magic link expired | Links expire after 15 minutes; resend the invitation |
| User can't see reports | Ensure reports have been shared with the client |
| Wrong client assigned | Remove and re-invite with correct client selected |
| User shows as Inactive | They haven't logged in recently; consider reaching out |
