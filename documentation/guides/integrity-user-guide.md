# Integrity Dashboard User Guide

**For:** Insight 360 Users
**Last Updated:** December 30, 2025

---

## Why Integrity Is Important

The Integrity Dashboard makes the invisible visible. Most organizations can't quantify what good ethics is worth—until something goes wrong. This dashboard provides:

- **Proactive measurement**: Track integrity before problems arise
- **ROI quantification**: Show the value of ethical practices
- **Early warning**: Detect issues through leading indicators
- **Stakeholder trust**: Build and measure organizational trust

---

## What It Does

The Integrity Dashboard monitors:

| Feature | Description |
|---------|-------------|
| **Integrity Yield** | Composite score of organizational ethics health |
| **Component Scores** | Four pillars of integrity measurement |
| **Leading Indicators** | Early warning signals |
| **Asset Status** | Track required data sources |
| **Action Items** | Recommended improvements |

## Step by Step Use

### Understanding the Dashboard

1. Navigate to **Integrity** in the sidebar
2. If configured, you'll see the full dashboard
3. If new, you'll see the setup wizard
4. The main display shows:
   - Large Integrity Yield score ring
   - Four component score cards
   - Indicator lists
   - Asset status grid

### The Integrity Yield Score

The central metric is the **Integrity Yield** (0-100):

| Score | Interpretation | Status |
|-------|----------------|--------|
| **80-100** | Strong Integrity Posture | Excellent |
| **60-79** | Adequate with Opportunities | Good |
| **40-59** | Significant Gaps | Needs Work |
| **0-39** | Critical Attention Needed | Urgent |

**Score Components:**
- Trust Velocity (30%)
- Intervention Effectiveness (25%)
- Alignment Audit (25%)
- Counterfactual Value (20%)

### Setting Up Your Dashboard

**Step 1: Define Bright Lines**
1. Click **Configure** on the Bright Lines card
2. Document your non-negotiable boundaries
3. These are lines you won't cross regardless of pressure
4. Examples: "No misleading customers", "No safety shortcuts"

**Step 2: Map Your Values**
1. Click **Configure** on the Values Map card
2. Document stated values (what you claim)
3. Document stress values (what you do under pressure)
4. Identify gaps between them

**Step 3: Start the Close Call Log**
1. Click **Start Log** on the Close Call card
2. Document near-misses and interventions
3. Record what could have gone wrong
4. Note who intervened and how

**Step 4: Research Industry Baseline**
1. Click **Research** on the Industry Baseline card
2. Document industry incidents and failures
3. Quantify costs of ethical lapses
4. Use as comparison for your organization

### Viewing Component Scores

Each of the four components measures different aspects:

**Trust Velocity (📈)**
- Are relationships compounding or eroding?
- Measures stakeholder trust over time
- Positive velocity = building trust
- Negative velocity = losing trust

**Intervention Effectiveness (⚡)**
- How well does human oversight work?
- Measures catch rate of potential issues
- High score = interventions are working
- Low score = issues slip through

**Alignment Audit (🎯)**
- Do stated values match stress values?
- Measures gap between words and actions
- High score = walk matches talk
- Low score = values drift under pressure

**Counterfactual Value (💰)**
- What's the ROI on integrity investments?
- Measures avoided costs
- Based on industry incidents you prevented
- Quantifies "nothing went wrong" value

### Monitoring Indicators

**Leading Indicators** (Early Warning):
- These predict future integrity issues
- Green = healthy signal
- Yellow = watch carefully
- Red = immediate attention

**Lagging Indicators** (Reference):
- These confirm past performance
- Historical validation of scores
- Used for trend analysis

### Tracking Asset Status

The Assets grid shows data source health:
- **Configured** = Data is available
- **Set Up** = Needs configuration
- Last updated timestamp shows freshness

**Required Assets:**
| Asset | Purpose |
|-------|---------|
| Bright Lines | Define boundaries |
| Values Map | Document values |
| Intervention Metrics | Track oversight |
| Trust Velocity | Measure relationships |
| Close Call Log | Record near-misses |
| Industry Baseline | External comparison |
| Integrity Yield | Composite calculation |

### Refreshing Data

1. Click **Refresh** button in header
2. Waits for data reload
3. All scores and indicators update
4. Asset timestamps refresh

## Tips for Best Results

### Building Foundation
- Start with Bright Lines and Values Map
- Be honest about stress values
- Document actual behavior, not aspirational

### Maintaining the System
- Update Close Call Log regularly
- Review Bright Lines quarterly
- Refresh Industry Baseline annually

### Using Insights
- Share scores with leadership
- Use in strategic planning
- Track trends over time
- Celebrate improvements

## Troubleshooting

**Dashboard shows setup wizard:**
- No integrity assets configured yet
- Follow the Quick Start Guide
- Configure required assets

**Scores showing zero:**
- Assets exist but lack data
- Review and populate asset content
- Ensure calculation inputs are present

**Assets not loading:**
- Check network connectivity
- Verify API is accessible
- Refresh the page

**Indicators not appearing:**
- Requires Integrity Yield asset
- Configure all foundation assets first
- Regenerate composite calculation
