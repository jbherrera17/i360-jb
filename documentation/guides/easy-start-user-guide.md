# Easy Start User Guide

**For:** Insight 360 Users
**Last Updated:** Monday, February 24, 2026

---

## Why Easy Start Is Important

Setting up a new AI workspace can be overwhelming. Easy Start removes that friction by turning the process into a conversation. Instead of hunting through menus to create agents, actions, and workflows manually, you simply tell Higgins about your work and challenges — and Higgins builds everything for you automatically.

Easy Start is the fastest path from a blank workspace to a fully equipped set of AI tools tailored to your specific role and needs.

---

## What It Does

| Action | Description |
|--------|-------------|
| **Conversational Discovery** | Higgins asks targeted questions to understand your role, daily tasks, and biggest pain points |
| **Custom Proposal** | Higgins presents a specific plan of 2–4 AI tools it will create for you, explained in plain language |
| **Guided Confirmation** | You review and approve (or adjust) the proposal before anything is created |
| **Automated Resource Creation** | Higgins creates agents, actions, and workflows in your workspace with one confirmation |
| **Live Progress Panel** | A panel on the right shows each resource as it is created, with a direct link to use it immediately |
| **Handoff to Execute 120** | After creation, Higgins directs you to Execute 120 where all your new tools are ready to use |

## Step by Step Use

### Phase 1: Welcome

1. Click **Easy Start** in the sidebar (look for the sparkles icon)
2. Higgins greets you and explains that it will ask a few questions before creating your tools
3. Type your first response in the message box at the bottom of the chat area
4. Press **Enter** or click the **Send** button (the arrow icon) to send your message

### Phase 2: Discovery

Higgins asks focused questions about your work — typically 2 to 4 exchanges. You might be asked about:

- Your role and team size
- Your most time-consuming recurring tasks
- Your biggest pain points or bottlenecks
- What success looks like for you day to day

Answer in your own words. The more specific you are, the better Higgins can tailor your tools. There are no wrong answers.

**Tip:** Higgins uses your exact language when naming and describing your tools. Describing a task as "writing the Monday morning status email" produces better results than "internal reporting."

### Phase 3: Proposal

After the discovery questions, Higgins presents a plan. Each proposed tool includes:

- A clear name
- A one-sentence description of what it does
- How it addresses the specific pain point you mentioned

The proposal typically includes a mix of:

| Resource Type | Best For |
|---------------|----------|
| **Agent** | Ongoing conversations with a specialist AI you return to repeatedly |
| **Action** | One-click tasks you need to run regularly (reports, summaries, drafts) |
| **Workflow** | Multi-step processes that involve inputs, AI generation, and review stages |

### Phase 4: Confirmation

Higgins asks for your approval before creating anything. You can:

- **Approve everything** — say "yes," "looks great," or similar
- **Request changes** — ask to rename something, swap one tool for another, or add a different type
- **Approve only some items** — tell Higgins which ones to create and which to skip

Nothing is created until you confirm.

### Phase 5: Creation

Once you approve, Higgins creates each tool one at a time. Watch the **Your New Tools** panel on the right side of the screen. As each resource is created, a card appears showing:

- The resource type (agent, action, or workflow)
- Its name and description
- A direct link to open or run it immediately

Higgins narrates each creation step in the chat so you know exactly what is being built.

### Phase 6: Handoff

When all tools are created, Higgins confirms what was built and directs you to **Execute 120** — the central hub where all your agents, actions, and workflows live. Click the **Go to Execute 120** button that appears at the bottom of the resources panel to navigate there directly.

## What Gets Created

### Agents

Agents are persistent AI specialists you can have ongoing conversations with. Agents created by Easy Start are:

- Placed in the **Execute suite** (available on Execute 120)
- Configured with a detailed system prompt tailored to your described needs
- Given conversation starters — example prompts you can click to begin a conversation
- Assigned a greeting message shown at the start of each chat

To use an agent later: go to **Execute 120**, find it in your department's Recommended Agents section, and click **Chat**.

### Actions

Actions are single-click AI operations for tasks you need to run repeatedly. Actions created by Easy Start are:

- Added to your **Execute suite** actions library
- Pre-configured with an AI prompt that executes the described task
- Available immediately in the Quick Actions section of Execute 120

To run an action later: go to **Execute 120**, find it in Quick Actions, and hover to reveal the play button. Or go to the **Actions** page to browse the full library.

### Workflows

Workflows are structured, multi-step processes that guide you through a task. Workflows created by Easy Start are:

- Built with 3 to 5 ordered steps covering inputs, AI generation, and review
- Available as Workflow Wizards in Execute 120
- Organized by category (automation, content, research, reporting, onboarding, review, or general)

To run a workflow later: go to **Execute 120**, find it in the Workflow Wizards section, and click **Start**.

## Where to Find Your Created Resources

All resources created by Easy Start appear in **Execute 120** (`/execute120`). They are organized by department (if Higgins assigned them to one) or visible under all departments.

You can also find them directly:

| Resource Type | Where to Find It |
|---------------|-----------------|
| Agents | **Agent Library** page — filter by category or search by name |
| Actions | **Actions** page — filter by suite or search by name |
| Workflows | **Execute 120** → Workflow Wizards section |

## Tips for Better Results

- **Be specific about pain points.** "I spend two hours every Friday pulling metrics from three spreadsheets into a status report" will produce a more useful tool than "I do reporting."
- **Mention your industry or domain.** Higgins writes better system prompts when it knows you work in healthcare, legal, SaaS, coaching, etc.
- **Name your outputs.** If you always produce something called a "Weekly Pulse Report" or "Client Discovery Summary," use that exact name — Higgins will use it too.
- **You can run Easy Start more than once.** Each session creates a new set of tools. Start fresh to build tools for a different role or workflow.
- **Review and edit after creation.** Easy Start creates a solid starting point. You can always open an agent or action in its editor to refine the system prompt, adjust the tone, or add context assets.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Higgins creates a tool before you confirm | This should not happen. Easy Start is designed to wait for your explicit approval. If it occurs, delete the unwanted resource from the Agent Library or Actions page. |
| "Agent limit reached" error appears | Your subscription tier has a maximum number of agents. Higgins will tell you the current count and limit. Consider deleting unused agents or contact your administrator about upgrading your plan. |
| "Action limit reached" or "Workflow limit reached" | Same as above — your plan's resource limit has been reached for that type. |
| A created resource does not appear in Execute 120 | Wait a few seconds and refresh the page. If it still does not appear, check the Agent Library or Actions page directly. |
| The conversation resets unexpectedly | Easy Start does not persist sessions across page reloads. If you reload the page, the conversation starts fresh. Complete the full session without reloading. |
| Higgins stops responding mid-creation | The request may have timed out (3-minute limit per exchange). Reload the page and describe what you want in a new session — any resources already created are saved in your workspace. |
| The "Your New Tools" panel is empty after creation | Refresh the page. If resources were created, they will still be available in Execute 120 and the Agent Library even if the panel did not update. |
| Guardrail blocked message appears | Your organization's soul configuration has blocked a specific type of request. Rephrase your description to focus on your actual business task, or contact your administrator. |
