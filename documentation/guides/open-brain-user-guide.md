# Open Brain User Guide

**For:** Insight 360 Users
**Last Updated:** 2026-03-17

---

## Why Open Brain Matters

Open Brain is your personal thought capture and retrieval system. It stores ideas, observations, people notes, and project tasks with automatic embedding generation for semantic search. Every thought you capture becomes searchable knowledge that AI assistants (like Higgins) can reference during conversations.

---

## What It Does

| Action | Description |
|--------|-------------|
| **Capture thoughts** | Save ideas, observations, references, tasks, and people notes |
| **Browse by category** | View thoughts organized as Ideas, Content, People, or Projects |
| **Semantic search** | Find thoughts by meaning, not just keywords |
| **Chat interface** | Use natural language to search, filter, and capture via the chat panel |
| **Detail view** | Click any card to see full content, tags, and metadata |

---

## Page Layout

The page has two panels:

- **Dashboard (left)** — Category pills, filters, and a card grid showing your thoughts
- **Chat Panel (right)** — An embedded AI assistant that can search, filter, and capture thoughts

---

## Step by Step Use

### Browsing Thoughts

1. Click a **category pill** (Ideas, Content, People, Projects) to filter by type
2. Hold **Shift + click** to view multiple categories simultaneously
3. Use the **time filter** dropdown to narrow by date range
4. Use the **sort** dropdown to change ordering
5. Type in the **search box** for keyword/semantic search

### Capturing a Thought

**Via chat panel:**
1. Type `capture: Your thought here` in the chat input
2. Or click the **+ Capture** chip for quick entry
3. The thought is saved and the grid refreshes automatically

### Using the Chat Panel

The chat panel understands natural language commands:

| Say This | What Happens |
|----------|-------------|
| "Show me ideas" | Switches to the Ideas category |
| "Show people notes" | Switches to People category |
| "Show all" | Shows all categories |
| "Ideas from last week" | Ideas + 7-day filter |
| "Find anything about strategy" | Semantic search across all thoughts |
| "Capture: We should try X" | Saves a new thought |

### Viewing Details

1. Click any thought card to open the detail slide-over
2. See full content, all tags, and people mentions
3. Click outside or press **Escape** to close

---

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Cmd/Ctrl + K** | Focus the chat input |
| **Escape** | Close detail panel |
| **Enter** | Send chat message |
| **Shift + Enter** | New line in chat |

---

## Tips & Best Practices

- Write thoughts as clear, standalone statements that make sense out of context
- Use the chat panel for quick operations — it's faster than clicking through filters
- Open Brain automatically extracts topics and people from your thoughts
- Thoughts captured here are also available to Higgins during chat conversations

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| "Open Brain MCP is not configured" | Contact your platform admin to set up Open Brain credentials |
| No thoughts showing | Check that your category filter is correct; try "Show all" in chat |
| Chat not responding | Check your internet connection; the chat uses streaming which requires a stable connection |
| Cards show wrong data | Try a hard refresh (Cmd+Shift+R) to clear cached data |
