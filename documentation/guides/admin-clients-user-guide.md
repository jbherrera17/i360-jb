# Client Management User Guide

**For:** Insight 360 Users
**Last Updated:** January 22, 2026

---

## Why Client Management Is Important

Client Management is essential for agencies and consultancies using Insight 360. It allows you to organize your work by client, track engagements, and maintain clear separation between different client projects. Each client can have their own sessions, profiles, and AI-generated insights without cross-contamination of data.

---

## What It Does

| Action | Description |
|--------|-------------|
| **View Clients** | See all clients for your organization |
| **Add Clients** | Create new client records |
| **Edit Clients** | Update client information and status |
| **Search/Filter** | Find clients by name, email, or status |
| **Archive Clients** | Soft-delete clients while preserving data |
| **Track Statistics** | View session and profile counts per client |

---

## Step by Step Use

### Viewing Your Clients

1. Navigate to **Client Management** from the sidebar
2. Select your organization from the dropdown
3. View client cards showing:
   - Client name and contact info
   - Status badge (Active, Prospect, Paused, Archived)
   - Quick statistics

### Adding a New Client

1. Click the **Add Client** button
2. Fill in the client details:
   - **Client Name** (required): Company or individual name
   - **Contact Name**: Primary point of contact
   - **Contact Email**: Email address
   - **Phone**: Contact phone number
   - **Notes**: Additional information or context
3. Click **Create Client**

### Editing a Client

1. Find the client card you want to edit
2. Click the **Edit** button
3. Update the fields as needed
4. Change **Status** if the engagement state has changed:
   - **Prospect**: Potential client, not yet engaged
   - **Active**: Currently working with this client
   - **Paused**: Engagement temporarily on hold
   - **Archived**: Engagement ended, preserved for records
5. Click **Save Changes**

### Searching and Filtering

**Search:**
1. Type in the search box at the top
2. Results filter by client name, contact name, or email
3. Clear the search box to show all clients

**Filter by Status:**
1. Use the status dropdown filter
2. Select a specific status (Active, Prospect, etc.)
3. Select "All Statuses" to clear the filter

### Archiving a Client

1. Find the client card
2. Click the **Archive** button
3. Confirm the archive action

**Note:** Archived clients are hidden from the default view but can be found using the status filter. Their data is preserved.

## Client Statuses Explained

| Status | Description | Use Case |
|--------|-------------|----------|
| **Prospect** | Potential client | Initial conversations, proposals |
| **Active** | Engaged client | Ongoing work, regular sessions |
| **Paused** | Temporary hold | Client on vacation, budget pause |
| **Archived** | Completed/Ended | Engagement complete, for records |

| Role | View | Add | Edit | Archive |
|------|------|-----|------|---------|
| **Owner** | Yes | Yes | Yes | Yes |
| **Admin** | Yes | Yes | Yes | Yes |
| **Consultant** | Yes | Yes | Yes | No |
| **Viewer** | Yes | No | No | No |

---

## Tips & Best Practices

- **Use descriptive names**: Include company name and project if working with the same client on multiple engagements
- **Keep contacts updated**: Maintain accurate contact information for smooth communication
- **Status discipline**: Update status promptly when engagement state changes
- **Archive don't delete**: Archive completed engagements to preserve history
- **Notes field**: Use notes for important context that doesn't fit elsewhere

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Can't add client | Check that you have Consultant, Admin, or Owner role |
| Can't see Archive button | Only Admin and Owner roles can archive clients |
| Client disappeared | Check the status filter - they may have been archived |
| Search not working | Search is case-insensitive; try partial names |
| Changes not saving | Ensure all required fields (Client Name) are filled |
| "Organization required" error | Make sure you've selected an organization from the dropdown |
