# Artifacts User Guide

**For:** Insight 360 Users
**Last Updated:** 2026-03-20

---

## Why Artifacts Matter

Artifacts are the persistent outputs of your AI-powered work. When agents run, skills execute, or workflows complete, their deliverables are saved as artifacts so you can browse, search, download, and version them.

---

## What It Does

| Action | Description |
|--------|-------------|
| **Browse** | View all artifacts in a filterable, searchable grid |
| **Filter** | Narrow by source type (Agent, Skill, Workflow, Chat, Upload) |
| **Search** | Find artifacts by name or description |
| **Preview** | Read text content inline without downloading |
| **Download** | Download binary files (images, PDFs, spreadsheets) |
| **Upload** | Manually create artifact bundles for reference material |
| **Version** | Create new versions of existing artifacts |

---

## Step by Step Use

### Browsing Artifacts

1. Navigate to **Artifacts** from the sidebar (under AI 360 Systems)
2. Browse the card grid showing all your organization's artifacts
3. Use the **filter chips** to narrow by source type
4. Use the **search bar** to find artifacts by name

### Viewing an Artifact

1. Click any artifact card to open its detail view
2. The detail shows:
   - Source type and creation date
   - Description and tags
   - All parts (text, images, files) with preview/download options
3. Click **Preview** on text parts to read them inline
4. Click **Download** on binary parts to get a signed download URL

### Creating a Manual Artifact

1. Click the **Upload** button in the page header
2. Fill in the name, description, and tags
3. Choose visibility (Private, Team, or Organization)
4. Click **Create Artifact**

### From Execute 120

The **My Artifacts** card on your Execute 120 command center shows your 5 most recent artifacts with quick links to view them.

## Artifact Types

Artifacts can contain multiple **parts** in a single bundle (compound artifacts):

- **Markdown** - Formatted text content (reports, briefs, analyses)
- **HTML** - Rich content with formatting
- **JSON** - Structured data outputs
- **Code** - Generated code snippets
- **Image** - Generated or uploaded images
- **PDF** - Document files
- **Spreadsheet** - Data tables and models
- **Audio/Video** - Media files
- **CSV** - Tabular data

---

## Visibility Levels

| Level | Who Can See |
|-------|-------------|
| **Private** | Only you |
| **Team** | Members of your department |
| **Organization** | Everyone in your organization |

---

## Tips & Best Practices

- Use descriptive names and tags to make artifacts easy to find later
- Set visibility to "team" or "org" for deliverables that colleagues need
- Use versioning when iterating on an artifact rather than creating new ones
- Check the Execute 120 card for quick access to recent work

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Artifact not showing | Check if the correct filter is active; try clearing filters |
| Download not working | Signed URLs expire after 1 hour; refresh and try again |
| Cannot see team artifacts | Verify you belong to the same department as the artifact creator |
| Upload button missing | The Artifacts module may not be enabled for your subscription tier |
