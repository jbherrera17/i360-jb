# Client Onboarding Steps

A step-by-step guide for onboarding a new client after technical setup is complete.

---

## Phase 1: Company Foundation (Day 1)

### 1.1 Company Profile

Help the client complete their company profile in Align 120:

| Field | Description | Example |
|-------|-------------|---------|
| Company Name | Legal/brand name | "Acme Corp" |
| Industry | Primary industry | "Technology" |
| Industry Segment | Specific niche | "B2B SaaS" |
| Company Size | Scale category | "medium" (51-500) |
| Employee Count | Current headcount | 150 |
| Founding Year | Year established | 2018 |
| Headquarters | Main location | "Austin, TX" |

### 1.2 Strategic Foundations

Capture the client's strategic direction:

| Element | Question to Ask |
|---------|-----------------|
| **Vision** | "Where do you want to be in 3-5 years?" |
| **Mission** | "Why does your company exist today?" |
| **Core Values** | "What 3-5 principles guide your decisions?" |
| **Planning Period** | "What's your current planning horizon?" |

### 1.3 Customize Departments

Review and customize the 6 default departments:

- Rename if needed (e.g., "Sales" → "Revenue")
- Adjust taglines to match culture
- Update metrics targets
- Customize quick prompts

## Phase 2: Context Population (Days 2-3)

### Priority 1: Core Context (Required)

These assets power AI responses immediately:

| Asset | What to Gather |
|-------|----------------|
| **Company Description** | About us page, elevator pitch, history |
| **Products/Services** | Product sheets, features, pricing |
| **Voice DNA** | Brand guidelines, writing style, tone |
| **ICP** | Customer profiles, segments, personas |
| **Core Values** | Values statement with examples |

### Priority 2: Competitive Context

| Asset | What to Gather |
|-------|----------------|
| **Why We Win** | Differentiators, unique value prop |
| **Competitors** | Competitor names, positioning, weaknesses |
| **Pain Points** | Customer challenges you solve |

### Priority 3: Supporting Context

| Asset | What to Gather |
|-------|----------------|
| **Case Studies** | Success stories, testimonials |
| **FAQs** | Common questions, objection handling |
| **Team Bios** | Key people, expertise areas |
| **Templates** | Email templates, proposal formats |

---

## Phase 3: User Setup (Day 3)

### 3.1 Create User Accounts

For each team member:

1. Create account via signup or admin
2. Set appropriate role:
   - `admin` - Full access, can manage system
   - `user` - Standard access to all features
   - `viewer` - Read-only access
3. Assign to department

### 3.2 Admin User Checklist

Ensure admin users can:
- [ ] Access all pages
- [ ] Create/edit agents
- [ ] Manage context assets
- [ ] View all departments
- [ ] Run any workflow

### 3.3 User Onboarding Sessions

Schedule brief sessions to walk users through:
1. Login and profile setup
2. Dashboard overview
3. Using agents in chat
4. Running their first workflow
5. Creating context assets

---

## Phase 4: Strategic Setup (Days 4-5)

### 4.1 Strategic Themes

Help define 2-4 strategic themes:

| Theme Example | Description |
|---------------|-------------|
| Market Expansion | Enter 3 new markets |
| Product Innovation | Launch 2 new products |
| Operational Excellence | Reduce costs by 15% |
| Customer Success | Increase retention to 95% |

### 4.2 Balanced Scorecard

Configure BSC objectives for each perspective:

**Financial**
- Revenue growth target
- Profitability goals
- Cash flow objectives

**Customer**
- NPS/CSAT targets
- Retention goals
- Acquisition metrics

**Internal Process**
- Efficiency metrics
- Quality standards
- Innovation targets

**Learning & Growth**
- Training goals
- Culture metrics
- Capability development

### 4.3 OKRs

Create initial OKRs at each level:

1. **Company OKRs** (3-5 objectives)
2. **Department OKRs** (per department)
3. **Link to Strategic Themes**

---

## Phase 5: Agent Customization (Days 5-6)

### 5.1 Review Default Agents

Walk through each agent and:
- Confirm relevance to client
- Adjust system prompts if needed
- Map to departments

### 5.2 Create Custom Agents (Optional)

For client-specific needs:
- Industry-specific agents
- Role-specific assistants
- Process-specific helpers

### 5.3 Department-Agent Mapping

Ensure each department has:
- 2-3 featured agents
- Relevant use case summaries
- Appropriate sort order

---

## Phase 6: Workflow Customization (Days 6-7)

### 6.1 Review Default Workflows

For each department, review:
- Campaign Strategy Builder (Marketing)
- Proposal Builder (Sales)
- SOP Creator (Operations)
- Board Meeting Prep (Executive)
- Investment Analysis (Finance)

### 6.2 Customize Steps

Adjust workflow steps for client needs:
- Rename fields
- Add/remove steps
- Update prompts
- Change agent assignments

### 6.3 Create Custom Workflows (Optional)

Common custom workflows:
- Client-specific approval processes
- Industry compliance workflows
- Unique deliverable generation

---

## Phase 7: Training & Handoff (Days 7-10)

### 7.1 Training Sessions

| Session | Duration | Audience |
|---------|----------|----------|
| Admin Training | 2 hours | System admins |
| User Training | 1 hour | All users |
| Executive Overview | 30 min | Leadership |
| Department Deep-Dives | 1 hour each | Dept teams |

### 7.2 Documentation Handoff

Provide client with:
- [ ] Login credentials
- [ ] Admin access details
- [ ] User guides (link to help)
- [ ] API documentation (if needed)
- [ ] Support contact info

### 7.3 Success Metrics

Establish KPIs for adoption:
- Weekly active users
- Workflows completed
- Context assets created
- AI queries processed
