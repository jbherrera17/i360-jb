## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.49 delivers **Phase 57b: Legacy Agency Tier Cleanup**, **Phase 58: Email Invitation System**, and **Research Studio Modernization** — completing the agency tier migration, replacing password-based user creation with Supabase email invitations, and upgrading Research Studio with ModalService, SSRF protection, and flashcard fixes.

## What's New in v3.49

### Phase 57b: Legacy Agency Tier Cleanup

| Component | Description | Impact |
|-----------|-------------|--------|
| **Delete agency tier row** | `DELETE FROM subscription_tiers WHERE id = 'agency'` | Clean database, no dead rows |
| **CHECK constraint update** | Remove `'agency'` from `organizations_subscription_tier_check` | Prevents invalid tier assignment |
| **Codebase cleanup** | Remove all hardcoded `'agency'` references across 6 files | Consistent sub-tier usage everywhere |
| **Conditional fixes** | `tier === 'agency'` → `tier.startsWith('agency')` | Agency features work for all sub-tiers |

### Phase 58: Email Invitation System

| Component | Description | Impact |
|-----------|-------------|--------|
| **Invite-based creation** | `inviteUserByEmail()` replaces `createUser()` with password | Users set their own passwords |
| **Accept-invite endpoint** | `POST /api/auth/accept-invite` validates token, sets password, activates | Secure self-service activation |
| **Accept-invite UI** | New form on login.html with password/confirm fields | Seamless invite acceptance |
| **Token detection** | URL hash `type=invite` routes to accept-invite flow | Automatic flow routing |
| **Invited status** | New `invited` status with badge, filter, resend action | Full invite lifecycle visibility |
| **Auto-invite on org add** | Adding non-existing email creates user and sends invite | One-step team building |
| **Rate limit handling** | 429 status for Supabase email rate limits | Graceful error messaging |

### Research Studio Modernization

| Component | Description | Impact |
|-----------|-------------|--------|
| **ModalService migration** | Inline modals → ModalService for create/add-source/preview | Consistent UI patterns |
| **Toast notifications** | All `alert()` → `showToast()` | Better user feedback |
| **Page template fix** | Standard app-container/aside/header structure | Consistent layout |
| **Flashcard bug fix** | `nextFlashcard()` used wrong state variable | Flashcard navigation works |
| **Flashcard shuffle** | Fisher-Yates shuffle for card decks | Better study experience |
| **Source editing** | PATCH sources with title/content, re-chunks on change | Editable research sources |
| **SSRF protection** | Block localhost, private IPs, cloud metadata in URL sources | Security hardening |
| **Supabase injection** | `setSupabase()` on sourceProcessor and studioOutputService | Testability |

## Access Control Layers

Version 3.49 adds email invitation flow to the authentication layer:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/invited/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **1c. Invitation** | Email invite → accept → set password → activate | New user onboarding |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **6. Ethical** | Soul config bright lines + guardrails | AI responses |
