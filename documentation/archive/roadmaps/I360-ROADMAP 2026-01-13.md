## What's New in v3.7

### Modal Resize Functionality Enhancement

| Component | Description |
|-----------|-------------|
| **8 Resize Handles** | 4 edges (top, bottom, left, right) + 4 corners |
| **CSS Override Fix** | `!important` declarations to override page-specific styles |
| **Handle Positioning** | Corners at -8px outside boundary, edges at -4px |
| **Cursor Tracking** | Proper edge anchoring for smooth Y-axis resize |
| **Visual Indicator** | Bottom-right corner resize grip |

### Key Fixes

| Issue | Solution |
|-------|----------|
| Handles overridden by page CSS | Added `!important` and explicit `auto` values |
| Corner handles under header | Positioned handles outside modal boundary |
| Y-axis cursor drift | Store bottom/right edges for proper anchor calculations |
| Stale handles in DOM | Remove existing handles before adding new set |

### Files Modified

| File | Changes |
|------|---------|
| `public/js/modal-manager.js` | Complete resize handle overhaul with CSS fixes |
