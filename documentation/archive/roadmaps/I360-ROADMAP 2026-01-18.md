## What's New in v3.15

### Context Asset Version History Fix (Bug Fix)

| Component | Description |
|-----------|-------------|
| **Root Cause** | Database trigger on `context_assets` auto-creates version history entries on UPDATE |
| **Problem** | Duplicate key constraint violation caused entire transaction to rollback |
| **Solution** | Delete conflicting version entry before update to allow trigger to succeed |

### Files Modified

| File | Change |
|------|--------|
| `server/routes/context.js` | Fix version conflict handling in PUT and rollback endpoints |
