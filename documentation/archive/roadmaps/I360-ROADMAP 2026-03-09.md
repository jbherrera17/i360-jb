## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.63 delivers **Phase 65: Integrity Dashboard Overhaul** — a comprehensive rebuild connecting real data sources to all four integrity components (Alignment Audit uses valuesAlignmentService, Counterfactual Value parses industry baseline financial data, Trust Velocity tracks historical trends), adding expandable detail panels to all component cards, a period selector (7/30/90 days), AI-powered industry baseline generation in the Soul Wizard, and Industry Baseline in the onboarding checklist.

## What's New in v3.62

### Phase 64: Branding System Fix & Font Unification

| Component | Description | Impact |
|-----------|-------------|--------|
| **authFetch Content-Type fix** | Global `auth-fetch.js` was missing `Content-Type: application/json` header; browser defaulted to `text/plain`, causing Express to ignore request bodies | All PUT/POST requests via `authFetch` now send JSON correctly; fixes branding saves and potentially 13 other pages |

## Access Control Layers

Version 3.63 maintains the 6-layer access control with guardrail enforcement fully wired:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/invited/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **1c. Invitation** | Email invite → accept (PKCE or legacy) → set password → activate | New user onboarding |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** + social_posts and social_channels resource checks | Module access |
| **2b. Tier UI** | Admin page hides agency-only elements for non-agency orgs | UI visibility |
| **3. Module** | can_access_module() RPC — enforces platform_admin_only flag | Feature routes |
| **3b. Platform Admin Only** | platform_admin_only column on platform_modules — denies all non-platform-admins | Open Brain + future restricted modules |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **5b. Favorites** | user_favorites table for per-user pinning across 5 entity types | Personal curation |
| **5c. Hidden Items** | user_hidden_items table for per-user dismiss across 5 entity types | Personal curation |
| **6. Ethical** | Soul config bright lines + guardrails + prompt injection detection + enforcement service | AI responses |
