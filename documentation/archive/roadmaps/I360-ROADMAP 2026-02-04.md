## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, and now a comprehensive **Human Values Definition System**. Version 3.36 delivers **Phase 54b: Multi-LLM Fixes & Chat Image Generation** — critical bug fixes for GPT-5.2 Pro, Gemini CircuitBreaker, and Nano Banana Pro provider detection, plus native image generation support in the chat interface.

## Access Control Layers

Version 3.35 adds an ethical evaluation layer:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **6. Ethical** | Soul config bright lines + guardrails | AI responses |
