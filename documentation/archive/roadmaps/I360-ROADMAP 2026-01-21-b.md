## What's New in v3.22

### Phase 38.2: Admin Enhancements

| Feature | Description |
|---------|-------------|
| **Conversations Admin Panel** | View/manage all user conversations with filters |
| **Conversation Statistics** | Total count, by department, by role |
| **Conversation Detail Modal** | View full conversation with messages |
| **Quick Prompts Admin** | Configure Execute 120 prompts per department |
| **Users API** | New `/api/users` endpoint for user management |
| **Department CRUD** | Full create/update/delete for departments |

### New API Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `GET /api/conversations/admin/all` | GET | List all conversations with user info |
| `GET /api/conversations/admin/stats` | GET | Conversation statistics |
| `GET /api/conversations/admin/:id` | GET | Get conversation detail |
| `DELETE /api/conversations/admin/:id` | DELETE | Delete conversation |
| `GET /api/users` | GET | List users with filters |
| `GET /api/users/:id` | GET | Get single user |
| `PUT /api/users/:id` | PUT | Update user |
| `PUT /api/departments/:id` | PUT | Update department |
| `POST /api/departments` | POST | Create department |
| `DELETE /api/departments/:id` | DELETE | Delete department |
