## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, and agency capabilities. Version 3.25 delivers **Enterprise Multi-Tenancy** — a complete subscription tier system, platform administration, and unified user management.

## What's New in v3.25

### Phase 44: Enterprise Multi-Tenancy

| Feature | Description |
|---------|-------------|
| **Subscription Tiers** | 4-tier system: Starter, Business, Enterprise, Agency |
| **Module Access Control** | Feature gating by tier and business role |
| **Platform Administration** | Synergi super-admin dashboard |
| **Tier Configuration** | Editable limits and features per tier |
| **Unified User Management** | Single UI for Platform, Agency, Client users |
| **Resource Limit Enforcement** | All creation endpoints check tier limits |
| **Dynamic Navigation** | Navigation built from accessible modules |

### New Pages Added

| Page | Purpose |
|------|---------|
| `admin-platform.html` | Platform admin dashboard |
| `admin-tier-setup.html` | Tier configuration |

### New API Endpoints

| Endpoint | Purpose |
|----------|---------|
| `/api/platform/*` | Platform administration |
| `/api/modules/*` | Module access management |
| `/api/users/unified` | Aggregated user data |
| `/api/users/:id/assignments` | User assignment management |
