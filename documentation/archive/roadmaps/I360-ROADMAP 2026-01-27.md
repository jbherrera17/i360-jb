## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, and agency capabilities. Version 3.29 completes **Phase 48 Platform Admin Enhancements** with direct user creation and consolidated tier management.

## Access Control Layers

Version 3.29 maintains the comprehensive four-layer access control system:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive | Login gate |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
