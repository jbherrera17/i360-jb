## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.60 delivers **Phase 61d: Social Publishing UX Improvements, Platform Admin Access & LLM Registry Sync** — social publishing improvements including platform admin access to social config via `is_platform_admin()` RPC, optional Postiz Org ID, account sync UX with "Manage in Postiz" and "Sync Accounts" buttons, org ID localStorage key fix, and LLM registry synchronization with current provider models.

## What's New in v3.60

### Phase 61d: Social Publishing UX Improvements, Platform Admin Access & LLM Registry Sync

| Component | Description | Impact |
|-----------|-------------|--------|

## Access Control Layers

Version 3.60 maintains the 6-layer access control with guardrail enforcement fully wired:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/invited/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **1c. Invitation** | Email invite → accept (PKCE or legacy) → set password → activate | New user onboarding |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** + social_posts and social_channels resource checks | Module access |
| **2b. Tier UI** | **Admin page hides agency-only elements for non-agency orgs** | UI visibility |
| **3. Module** | can_access_module() RPC — **used by Execute 120 for conditional cards** | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **5b. Favorites** | **user_favorites table for per-user pinning across 5 entity types** | Personal curation |
| **5c. Hidden Items** | **user_hidden_items table for per-user dismiss across 5 entity types** | Personal curation |
| **6. Ethical** | Soul config bright lines + guardrails + prompt injection detection + enforcement service | AI responses |
