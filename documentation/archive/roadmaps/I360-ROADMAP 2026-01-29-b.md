## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, and external integrations. Version 3.32 delivers **Phase 50: Database Security Hardening** — resolving all 29 Supabase linter security warnings by converting SECURITY DEFINER views to SECURITY INVOKER and enabling RLS on exposed tables.

## Access Control Layers

Version 3.32 maintains the comprehensive four-layer access control system:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive | Login gate |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |

**New:** All views now use `SECURITY INVOKER`, ensuring RLS policies are respected when querying through views.
