## Executive Summary

Insight 360 is a **Values-Based AI Ecosystem** — a personal AI command center that aligns automated systems with organizational ethics. Version 3.60 delivers **Phase 61d**, a set of social publishing UX improvements and LLM registry maintenance: (1) **Platform admin access to social config** — platform admins (Synergi) can now configure social publishing for any org via `is_platform_admin()` RPC check, not just org owners/admins; (2) **Postiz Org ID now optional** — API key is the only required field for social publishing configuration, simplifying setup; (3) **Account sync UX** — new "Manage in Postiz" and "Sync Accounts" buttons on the Connected Accounts tab, replacing inline OAuth flow with a clearer Postiz-first workflow; (4) **Org ID localStorage fix** — social media page now reads `insight360_org_id` (matching the standard key) with fallback to `currentOrgId`; (5) **LLM registry sync** — provider model definitions updated to match current upstream availability.

## Phase 61d: Social Publishing UX Improvements, Platform Admin Access & LLM Registry Sync (v3.60)

### What Was Completed

Five deliverables were completed in this phase:

1. **Platform admin social config access** (`server/routes/social-publish.js`) — The PUT /config endpoint now checks `is_platform_admin()` RPC in addition to org membership role, allowing Synergi platform admins to configure social publishing for any organization without being an org member.

2. **Postiz Org ID made optional** (`server/routes/social-publish.js`, `server/services/postizService.js`) — The `postizOrgId` field is no longer required when configuring social publishing. The API key is sufficient. `configureOrg()` only updates `postiz_org_id` when provided, and `isConfigured()` only checks for the encrypted API key.

3. **Account sync UX improvements** (`public/social-media.html`) — Added "Manage in Postiz" button (opens Postiz integrations dashboard) and "Sync Accounts" button to the Connected Accounts tab. Platform connection flow simplified to open Postiz directly instead of attempting OAuth URL fetch. Instructional text added: "Connect accounts in Postiz, then sync them here."

4. **Org ID localStorage key fix** (`public/social-media.html`) — Changed from `insight360-org-id` to `insight360_org_id` (matching the standard used across other pages) with fallback to `currentOrgId` for backwards compatibility.

5. **LLM registry sync** (`server/services/llmRegistry.js`) — Provider model definitions synchronized with current upstream model availability.
