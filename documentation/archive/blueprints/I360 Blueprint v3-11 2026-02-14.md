## Phase 57: Module Add-on Pricing, Agent Introductions & Soul Config CRUD

Three major feature areas: a public pricing API with module add-on purchasing, rich agent introductions with conversation starters, and full CRUD capabilities for the soul configuration UI.

### Module Add-on Pricing System

Enables individual platform modules to be priced and purchased as add-ons beyond what a tier includes.

#### Database Schema (`phase57-module-addon-pricing.sql`)

```sql
-- New pricing columns on platform_modules
ALTER TABLE platform_modules ADD COLUMN addon_price_monthly NUMERIC(10,2);
ALTER TABLE platform_modules ADD COLUMN addon_price_yearly NUMERIC(10,2);
ALTER TABLE platform_modules ADD COLUMN is_addon_purchasable BOOLEAN DEFAULT FALSE;
ALTER TABLE platform_modules ADD COLUMN addon_description TEXT;

-- New org_module_purchases table
CREATE TABLE org_module_purchases (
    id UUID PRIMARY KEY,
    org_id UUID REFERENCES organizations(id),
    module_id TEXT REFERENCES platform_modules(id),
    billing_period TEXT CHECK (IN ('monthly', 'yearly')),
    price_at_purchase NUMERIC(10,2),
    status TEXT CHECK (IN ('active', 'cancelled', 'expired')),
    stripe_subscription_id TEXT,
    UNIQUE(org_id, module_id)
);
```

#### Updated `can_access_module()` Function

The database function now checks `org_module_purchases` when a tier check fails — if the org purchased the module as an active add-on, the tier gate is bypassed while role and override checks still apply.

#### Public Pricing API (`server/routes/pricing.js`)

Unauthenticated endpoints (whitelisted in auth middleware) for public-facing pricing pages:

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/pricing/tiers` | All active subscription tiers with prices and limits |
| GET | `/api/pricing/modules` | All active modules grouped by nav_group with addon pricing |
| GET | `/api/pricing/comparison` | Tier × module matrix (included/addon/unavailable) |

#### Platform Admin Add-on Management (`server/routes/platformAdmin.js`)

| Method | Route | Description |
|--------|-------|-------------|
| PUT | `/api/platform/modules/:id/addon-pricing` | Set module add-on pricing |
| GET | `/api/platform/orgs/:orgId/addons` | List org's purchased add-ons |
| POST | `/api/platform/orgs/:orgId/addons` | Purchase add-on for org |
| DELETE | `/api/platform/orgs/:orgId/addons/:moduleId` | Cancel org add-on |

#### Tier Modules Nav Group Grouping

`GET /api/platform/tiers/:id/modules` now returns `by_nav_group` alongside `by_category`, with alias mapping (`systems` → `ai-systems`, `components` → `ai-systems`, `tools` → `modules`) matching the navigation sidebar categories.
