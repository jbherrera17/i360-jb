## Executive Summary

Insight 360 is a **Values-Based AI Ecosystem** — a personal AI command center that aligns automated systems with organizational ethics. Version 3.31 introduces **Phase 49: External Integrations Framework**, a pluggable architecture enabling i360 to connect to clients' existing systems (CRM, ERP, CMS) and per-user productivity tools (Google Workspace, Microsoft 365).

**Core Philosophy:** *"Technology should augment human brilliance—not replace it."*

## Phase 49: External Integrations Framework (v3.31)

### What Was Completed

Phase 49 delivers a complete integration framework with provider registry, OAuth/API key authentication, credential encryption, sync engine, webhook handling, and add-on pricing tied to subscription tiers.

### Feature 1: Integration Provider Registry

Pluggable provider architecture with standard interface for any external system:

| Component | Description |
|-----------|-------------|
| `baseProvider.js` | Abstract base class with OAuth, data ops, webhook methods |
| `credentialManager.js` | AES-256-GCM encryption, token refresh with 5-min buffer |
| `index.js` | Provider registry and factory |

### Feature 2: Google Workspace Provider

Per-user OAuth2 connections to Google services:

| Service | Capabilities |
|---------|-------------|
| **Gmail** | Read recent emails, send, manage labels |
| **Google Drive** | List/read/create files |
| **Google Calendar** | Read/create events |

### Feature 3: Client System Connectors

Connect to clients' existing CRM/ERP/CMS systems (not hosted by Synergi):

| Provider | Auth Type | Capabilities |
|----------|-----------|-------------|
| **Salesforce** | OAuth2 | Contacts, Accounts, Opportunities, Activities |
| **HubSpot** | OAuth2 | Contacts, Companies, Deals, Tickets |
| **Generic CRM** | API Key | Configurable field mapping, CRUD operations |
| **EspoCRM** | API Key | Full REST API (Synergi internal only) |
| **Strapi CMS** | API Key | Content types, media, search (Synergi internal only) |

### Feature 4: Sync Engine & Webhooks

| Component | Description |
|-----------|-------------|
| `syncEngine.js` | Background sync orchestration (full/incremental) |
| `webhookHandler.js` | Incoming webhook processing with signature verification |
| `webhooks.js` route | `/api/webhooks/:provider` endpoint |

### Feature 5: Integration Add-On Pricing

Integrations are billable add-ons, not included in base tiers:

| Add-On | Monthly Price | Available From |
|--------|:---:|:---:|
| Google Workspace | $99/user/mo | Business |
| Microsoft 365 | $99/user/mo | Business |
| Client CRM Connector | $299/mo | Enterprise |
| Client ERP Connector | $299/mo | Enterprise |
| Custom Integration | $199/mo + $2,500 setup | Enterprise Plus |

### Feature 6: Tier Integration Addon Management

Admin tier setup page extended with integration addon pricing configuration:

| Feature | Description |
|---------|-------------|
| Addon categories | Productivity, Client Systems |
| Per-category pricing | Monthly price, API call limits, user limits |
| Comparison table | Addon pricing across tiers |

### Feature 7: Google Context Injection

Agents can access connected Google data at runtime:

| Context Source | Description |
|---------------|-------------|
| Recent Emails | Gmail inbox summary injected into agent context |
| Upcoming Events | Calendar events for meeting prep |
| Recent Files | Drive files for document context |

### Feature 8: Integrations Dashboard

New `integrations.html` page with:

| Section | Description |
|---------|-------------|
| Connected Services | User's active integrations with status |
| Organization Integrations | Admin-only org-level connections |
| Available Add-Ons | Requestable integrations with pricing |

### Feature 9: Synergi Internal Infrastructure

Docker configuration for Synergi's own tools (not client-facing):

| Service | Purpose |
|---------|---------|
| EspoCRM | Synergi's sales pipeline and client management |
| Strapi CMS | Synergi's content, templates, knowledge base |

## Access Control Layers

Version 3.31 maintains the comprehensive four-layer access control system:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive | Login gate |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |

**New:** Integration add-ons are gated by tier (Business for productivity, Enterprise for client systems, Enterprise Plus for custom).
