## Technical Details

### GPT-5.2 Pro Fix

GPT-5.2 Pro is NOT a chat model — it requires the completions API (`/v1/completions`), not chat completions (`/v1/chat/completions`). The fix redirects requests to `gpt-5.2` which supports the chat interface:

```javascript
// server/services/openai.js
const MODEL_ALIASES = {
    'gpt-5.2-pro': 'gpt-5.2',  // Pro requires completions API, redirect to chat-capable model
    // ...
};
```

### Gemini CircuitBreaker Fix

The CircuitBreaker class requires the service name as the first constructor parameter:

```javascript
// Before (broken)
const circuitBreaker = new CircuitBreaker({
    failureThreshold: 3,
    timeout: 30000
});

// After (fixed)
const circuitBreaker = new CircuitBreaker('gemini', {
    failureThreshold: 3,
    timeout: 30000
});
```

And the method is `execute()`, not `call()`:

```javascript
// Before
return circuitBreaker.call(async () => { ... });

// After
return circuitBreaker.execute(async () => { ... });
```

### Nano Banana Provider Detection

Added prefix check for experimental Google models:

```javascript
// server/services/llmRegistry.js
if (modelId.startsWith('gemini') || modelId.startsWith('nano-banana')) return 'google';
```

### Image Size Normalization

New `normalizeImageSize()` function maps user-friendly terms to API-specific values:

```javascript
function normalizeImageSize(size, model) {
    const isGptImage = model.startsWith('gpt-image');
    const aliases = {
        '16:9': isGptImage ? '1536x1024' : '1792x1024',
        '9:16': isGptImage ? '1024x1536' : '1024x1792',
        'landscape': isGptImage ? '1536x1024' : '1792x1024',
        'portrait': isGptImage ? '1024x1536' : '1024x1792',
        'square': '1024x1024',
        '1:1': '1024x1024',
        'auto': isGptImage ? 'auto' : '1024x1024'
    };
    return aliases[size?.toLowerCase()] || size;
}
```

## API Endpoints

### Image Generation (New)

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/chat/image/generate` | Generate image from prompt |
| GET | `/api/chat/image/models` | List available image models |

#### Generate Image Request

```json
{
  "prompt": "A serene mountain landscape at sunset",
  "model": "gpt-image-1.5",
  "size": "16:9",
  "quality": "high"
}
```

#### Generate Image Response

```json
{
  "success": true,
  "images": [
    {
      "url": "https://...",
      "revised_prompt": "...",
      "model": "gpt-image-1.5",
      "size": "1536x1024"
    }
  ],
  "usage": {
    "prompt_tokens": 50,
    "total_tokens": 50
  }
}
```
