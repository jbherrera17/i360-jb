## Phase 40.1: UI Standardization (v3.23)

### Feature 1: Global CSS Standards

Standardized CSS classes in `styles.css` for consistent UI across all pages.

| Class | Purpose | Values |
|-------|---------|--------|
| `.page-container` | Content wrapper after header | `padding: var(--spacing-xl)` (2rem) |
| `.panel` | Any boxed content area | `border-radius: var(--radius-lg)` (12px) |
| `.panel-header` | Panel top section | Consistent padding, border |
| `.panel-body` | Panel content area | `padding: var(--spacing-lg)` (1.5rem) |
| `.panel-footer` | Panel bottom section | Matches header |
| `.stats-bar` | Metrics display row | 12px radius, flex layout |
| `.stat-item` | Individual stat | Column flex |
| `.stat-value` | Stat number | 1.5rem, bold |
| `.stat-label` | Stat description | 0.85rem, muted |
| `.filter-bar` | Search/filter controls | Flex wrap, proper gaps |
| `.search-box` | Search input wrapper | 8px radius |
| `.filter-select` | Dropdown filter | 8px radius |
| `.help-btn` | Help icon button | 36x36px, 8px radius |

### Feature 2: User-to-Organization Assignment

Enhanced user creation API to support direct organization membership.

| Parameter | Type | Description |
|-----------|------|-------------|
| `org_id` | UUID (optional) | Organization to add user to |
| `org_role` | string (optional) | Role: admin, consultant, viewer (default: consultant) |

**API Endpoint:** `POST /api/auth/users`

```json
{
  "email": "newuser@example.com",
  "password": "securePassword123",
  "display_name": "New Team Member",
  "role": "user",
  "org_id": "uuid-of-organization",
  "org_role": "consultant"
}
```

**Behavior:**
1. Creates user in Supabase Auth
2. Creates user profile with `default_org_id` set
3. Adds user to `organization_members` table
4. User immediately appears in Team Members page

## CSS Design System

### Spacing Variables

| Variable | Value | Usage |
|----------|-------|-------|
| `--spacing-xs` | 0.25rem | Tight gaps |
| `--spacing-sm` | 0.5rem | Small gaps |
| `--spacing-md` | 1rem | Medium gaps |
| `--spacing-lg` | 1.5rem | Large gaps |
| `--spacing-xl` | 2rem | Page padding |
| `--spacing-2xl` | 3rem | Extra large |

### Border Radius Variables

| Variable | Value | Usage |
|----------|-------|-------|
| `--radius-sm` | 4px | Small elements |
| `--radius-md` | 8px | Buttons, inputs |
| `--radius-lg` | 12px | Cards, panels |
| `--radius-xl` | 16px | Large panels |
| `--radius-full` | 9999px | Pills, circles |

## Migration Notes

### For New Pages

Use standardized classes instead of page-specific CSS:

```html
<div class="page-container">
    <div class="filter-bar">
        <div class="search-box">
            <input type="text" placeholder="Search...">
        </div>
        <select class="filter-select">...</select>
    </div>
    <div class="stats-bar">
        <div class="stat-item">
            <span class="stat-value">42</span>
            <span class="stat-label">Total Items</span>
        </div>
    </div>
    <div class="panel">
        <div class="panel-header"><h2>Title</h2></div>
        <div class="panel-body">Content</div>
    </div>
</div>
```

### For Existing Pages

Remove duplicate CSS definitions for:
- `.filter-bar`
- `.search-box`
- `.filter-select`
- `.stats-bar`, `.stat-item`, `.stat-value`, `.stat-label`
- `.help-btn`
- `.header-actions`
