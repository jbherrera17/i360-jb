### Visual Workflow Builder

A new drag-and-drop workflow designer allows users to create custom workflows without code.

#### Key Features

- **Step Library** - Categorized draggable step types (Input, AI Processing, Human Control, Output)
- **Canvas** - Timeline-based visual step layout with connectors
- **Step Editor** - Right panel for configuring step properties
- **Undo/Redo** - Full undo/redo stack for workflow editing
- **Save & Preview** - Save to database and preview workflow execution

#### Step Types Supported

| Type | Description | Configuration |
|------|-------------|---------------|
| `user_input` | Collect information from user | Input field definitions |
| `agent_chat` | Process with AI agent | Agent selection, prompt template |
| `skill_execution` | Run specialized skill | Skill selection, parameters |
| `research` | Web research via Perplexity | Research prompt template |
| `human_gate` | Approval checkpoint | Gate message, requires approval |
| `review` | Review & refine output | Review instructions |
| `output` | Final output compilation | Output format |
| `context_creation` | Create context asset | Asset type, fields |
| `artifact_generation` | Generate documents | Format, template |

#### Variable Interpolation

The engine supports template variable substitution from previous step outputs:

- `{{step_1.field_name}}` - Access specific field from step 1 output
- `{{step_2_output}}` - Access entire output from step 2
- `{{topic}}` - Access any variable by name

#### Context Building

Each agent step receives context from all previous step outputs:
