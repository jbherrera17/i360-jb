## What's Fixed in v3.1

### Navigation Panel Fixes

| Issue | Root Cause | Solution |

| Navigation blocked on Strategy page | Hidden modal overlays intercepting clicks | Added `pointer-events: none` to hidden `.modal-overlay` |

### Modal System Improvements

Added proper `.modal-overlay` styles to `styles.css`:

```css
/* Modal overlay - covers entire screen when active */
.modal-overlay {
    position: fixed;
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    background: rgba(0, 0, 0, 0.6);
    z-index: 2000;
    opacity: 0;
    visibility: hidden;
    pointer-events: none;  /* KEY FIX: Don't block clicks when hidden */
    transition: opacity var(--transition-base), visibility var(--transition-base);
    display: flex;
    align-items: center;
    justify-content: center;
}

.modal-overlay.active {
    opacity: 1;
    visibility: visible;
    pointer-events: auto;  /* Enable clicks when visible */
}
```

### Navigation Scroll Preservation

Added `setupScrollPreservation()` function to `navigation.js`:

```javascript
function setupScrollPreservation() {
    const sidebarNav = document.querySelector('.sidebar-nav');
    if (!sidebarNav) return;

    // MutationObserver restores scroll after DOM mutations
    const observer = new MutationObserver(() => {
        const targetScroll = parseInt(sidebarNav.dataset.targetScroll);
        if (!isNaN(targetScroll) && targetScroll > 0) {
            requestAnimationFrame(() => {
                sidebarNav.scrollTop = targetScroll;
            });
        }
    });

    observer.observe(sidebarNav, {
        childList: true,
        subtree: true,
        attributes: false
    });

    // Track user scroll position
    sidebarNav.addEventListener('scroll', () => {
        sidebarNav.dataset.targetScroll = sidebarNav.scrollTop;
    }, { passive: true });
}
```
