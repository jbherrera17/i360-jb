## Executive Summary

Insight 360 v3.6 implements the **LLM Model Availability Check System** (Phase 25), providing daily automated health checks of LLM provider APIs with admin on-demand checks and dashboard visibility. This release ensures proactive monitoring of AI service availability, detecting deprecated models, authentication issues, and service outages before they impact users.

**Key Achievements:**
- Implemented daily scheduled LLM provider availability checks
- Created dashboard card showing real-time provider status
- Added admin-only on-demand check functionality
- Fixed deprecated Perplexity `sonar-reasoning` model issue
- Added graceful handling for deprecated model auto-migration
- Created comprehensive database schema for check results storage

### Deprecated Model Handling

Fixed critical issue where the `sonar-reasoning` Perplexity model was deprecated:

```javascript
// server/services/perplexity.js
const DEPRECATED_MODELS = {
    'sonar-reasoning': 'sonar-reasoning-pro'  // Deprecated late 2025
};

function resolveModel(modelInput) {
    if (!modelInput) return 'sonar-pro';
    const normalized = modelInput.toLowerCase();

    if (DEPRECATED_MODELS[normalized]) {
        console.warn(`Perplexity model '${modelInput}' is deprecated, using '${DEPRECATED_MODELS[normalized]}' instead`);
        return DEPRECATED_MODELS[normalized];
    }
    // ... continues with model resolution
}
```

## Database Schema

### model_availability_checks Table

```sql
CREATE TABLE IF NOT EXISTS model_availability_checks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    provider TEXT NOT NULL,
    status TEXT NOT NULL CHECK (status IN ('available', 'deprecated', 'unavailable', 'auth_error', 'rate_limited')),
    error_message TEXT,
    response_time_ms INTEGER,
    checked_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_model_checks_checked ON model_availability_checks(checked_at DESC);
CREATE INDEX idx_model_checks_provider ON model_availability_checks(provider, checked_at DESC);
```

### model_check_config Table

```sql
CREATE TABLE IF NOT EXISTS model_check_config (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    schedule_time TIME DEFAULT '06:00:00',
    timezone TEXT DEFAULT 'America/New_York',
    is_enabled BOOLEAN DEFAULT true,
    last_run_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## Key Features

### 1. Minimal Cost Checks

Uses the cheapest models with `max_tokens: 1` to minimize API costs:

- **Anthropic:** `claude-haiku-4-5-20251001` (cheapest Claude model)
- **OpenAI:** `gpt-4o-mini` (cheapest GPT model)
- **Perplexity:** `sonar` (base model)

### 2. Graceful Degradation

When database tables don't exist, the system returns a valid response indicating tables are missing:

```javascript
if (checksError.code === 'PGRST205' || checksError.message.includes('not find')) {
    logger.warn('Model availability tables not yet created. Run: db/phase25-model-availability-schema.sql');
    return {
        success: true,
        lastChecked: null,
        providers: {},
        overallStatus: 'unknown',
        tablesMissing: true
    };
}
```

### 3. Admin-Only On-Demand Checks

The "Check Now" button is only visible to admin users and triggers an immediate availability check.

### 4. Scheduler Integration

Integrated with existing `schedulerService.js` for unified cron job management:

```javascript
// In initializeScheduler()
try {
    await modelAvailabilityService.initializeScheduler();
    console.log('[Scheduler] Model availability scheduler initialized');
} catch (modelError) {
    console.error('[Scheduler] Failed to initialize model availability scheduler:', modelError);
    // Non-critical - don't throw
}
```
