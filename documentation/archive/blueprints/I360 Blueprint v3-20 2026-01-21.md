## Phase 38.1: User Admin Bug Fixes (v3.20)

### Bug Fix 1: Column users.name Does Not Exist

Fixed SQL error when updating user business role via admin interface.

| Issue | Resolution |
|-------|------------|
| **Error** | `column users.name does not exist` |
| **Cause** | `business-roles.js` selecting non-existent `name` column |
| **Fix** | Changed to `display_name` column |
| **File** | `server/routes/business-roles.js:423` |

**Before:**
```javascript
.select('id, email, name, business_role')
```

**After:**
```javascript
.select('id, email, display_name, business_role')
```

### Bug Fix 2: Department Not Saving in User Edit

Fixed issue where editing a user's department in admin would not persist.

| Issue | Resolution |
|-------|------------|
| **Error** | Department changes not saved |
| **Cause** | PUT endpoint not extracting `department_id` from request body |
| **Fix** | Added `department_id` handling to update logic |
| **File** | `server/routes/auth.js:679` |

**Changes:**
```javascript
// Extract department_id from body
const { display_name, role, department_id } = req.body;

// Add to updates if present
if (department_id !== undefined) {
    updates.department_id = department_id;
}
```

### Bug Fix 3: Department Not Displayed in User List

Fixed issue where saved department wasn't visible in user management table.

| Issue | Resolution |
|-------|------------|
| **Error** | Department column always empty |
| **Cause** | GET endpoint not including `department_id` in select |
| **Fix** | Added `department_id` and `business_role` to query |
| **File** | `server/routes/auth.js:518` |

**Before:**
```javascript
.select('id, email, display_name, role, created_at, updated_at')
```

**After:**
```javascript
.select('id, email, display_name, role, department_id, business_role, created_at, updated_at')
```

### Bug Fix 4: Spurious "Failed to Load Users" Toast

Fixed error toast appearing after successful user save.

| Issue | Resolution |
|-------|------------|
| **Error** | "Failed to load users" shown after save success |
| **Cause** | Race condition in `loadData()` Promise.all error handling |
| **Fix** | Removed error toast, added defensive error handling |
| **File** | `public/admin.html:2110` |
