## Executive Summary

Insight 360 is a **Values-Based AI Ecosystem** — a personal AI command center that aligns automated systems with organizational ethics. Version 3.56 delivers **Phase 60**, which adds multi-platform social media publishing powered by Postiz. Users can compose, schedule, and publish content to 8 platforms (YouTube, Instagram, TikTok, Twitter/X, Facebook, LinkedIn, Pinterest, Threads) with per-platform content adaptation, usage-based pricing with post volume as the key metric, and full multi-tenant isolation via org-scoped encrypted API keys.

**Core Philosophy:** *"Technology should augment human brilliance—not replace it."*

## Phase 60: Social Media Publishing via Postiz Integration (v3.56)

### What Was Completed

Eleven deliverables were completed in this phase:

1. **Postiz Bridge Service** (`server/services/postizService.js`) — REST API bridge to Postiz with AES-256-GCM encrypted org-scoped API keys, circuit breaker (`postiz-api`), 30s timeout, 2 retries via withResilience(). Methods: configureOrg, isConfigured, getIntegrations, syncIntegrations, createPost, getScheduledPosts, cancelPost, uploadMedia, findOptimalSlot, getAnalyticsSummary.

2. **Content Adapter Service** (`server/services/contentAdapterService.js`) — Platform-specific content formatting: Twitter threading at 280 chars, LinkedIn 3000 chars with article links, Instagram 2200 chars with hashtag blocks, TikTok 2200 chars, Facebook 63K chars, YouTube title+description+tags split, Pinterest title+description (requires image), Threads 500 chars.

3. **Social Publishing API** (`server/routes/social-publish.js`) — 16 API endpoints at `/api/social/*` with module access middleware. Config (2), Accounts (3), Posts (5), Content Adaptation (2), Analytics (2), Media (1), Usage (1).

4. **Workflow Engine Extension** — New `social_publish` step type in workflowEngine.js for automated pipelines (generate content → adapt for platforms → schedule via Postiz).

5. **Database Schema** — 3 new tables: `social_posts`, `social_platform_connections`, `social_post_analytics` with RLS policies. Postiz config columns (`postiz_org_id`, `postiz_api_key_encrypted`) on organizations.

6. **Usage-Based Pricing** (Phase 60b) — `max_social_posts_monthly` and `max_social_channels` columns on `subscription_tiers`. Post volume as primary metric. Extended `check_org_limits()` with addon override support via `get_social_addon_limit()`. Addon pricing: $29/mo for Starter tier.

7. **Tier Limits:**

| Tier | Posts/Month | Channels |
|------|-----------|----------|
| Starter | 0 (addon: 100/$29/mo) | 0 (addon: 3) |
| Business | 500 | 5 |
| Enterprise | 2,000 | 15 |
| Agency Starter | 1,000 | 15 |
| Agency Pro | 5,000 | 50 |
| Agency Enterprise | Unlimited | Unlimited |

8. **Social Media Page** (`public/social-media.html`) — 5-tab UI: Connected Accounts (platform cards with connect/disconnect), Compose (platform selector, content editor with per-platform preview, usage bar, schedule picker), Scheduled (post list with cancel), History (published/failed posts), Analytics (engagement metrics).

9. **Admin Tier Setup** — `admin-tier-setup.html` updated with `max_social_posts_monthly` and `max_social_channels` in LIMIT_LABELS and save payload.

10. **95 Playwright Tests** — 62 UI tests + 33 API tests covering all social media functionality.

11. **Documentation** — User guide and technical guide created, registered in help system and docs route.
