## Phase 58b: Platform Admin Role Override (v3.50)

### What Was Completed

Platform administrators (users in the `platform_admins` table) were seeing their system-level role ("User") on the profile page instead of their platform admin role ("Super Administrator"). The navigation sidebar already had the correct override logic, but the profile page displayed both roles separately — a confusing UX. This phase unifies the role display so platform admin status overrides the system role everywhere.

### Changes

| Change | File(s) | Description |
|--------|---------|-------------|
| **Role badge override** | `public/profile.html` | `populateForm()` checks `is_platform_admin` first, displays platform role (e.g., "Super Administrator") with crown icon |
| **Unified role display** | `public/profile.html` | Removed separate "Platform Role" field — main role badge now shows platform admin role |
| **Crown icon** | `public/profile.html` | Role badge icon changes from `shield` to `crown` for platform admins, with gold `platform-admin` styling |
| **localStorage sync** | `public/profile.html` | On profile load, syncs `is_platform_admin` and `platform_admin_role` to localStorage for navigation consistency |
| **Navigation refresh** | `public/profile.html` | Triggers `initNavigation()` if platform admin status changed since login |

### Files Modified

| File | Changes |
|------|---------|
| `public/profile.html` | Role badge override logic, localStorage sync, platform admin group hidden |
