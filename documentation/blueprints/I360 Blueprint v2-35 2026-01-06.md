## What's New in v2.35

### Phase 17: Align 120 Module Results & Agent Execution

This release implements real agent execution in the Align 120 module, stores execution results, fixes agent category mappings, and adds session management features.

---

### Real Agent Execution

The Align 120 module now executes actual agents instead of returning placeholder data. Each module runs its assigned agents and stores the results.

#### Implementation

```javascript
// server/routes/align120.js
for (const agent of agents) {
    const result = await agentService.executeAgent(agent.id, {
        userMessage: contextMessage,
        userId: userId,
        conversationHistory: []
    });
    agentResults.push({
        agent_id: agent.id,
        agent_name: agent.name,
        response: result.response,
        execution_id: result.execution_id,
        usage: result.usage,
        duration_ms: result.duration_ms
    });
}
```

### Chat UX Improvements

#### User Message Visibility

When sending a message, the user's prompt now scrolls to the **top** of the chat viewport instead of the bottom. This keeps the user's question visible while the AI response streams below it.

**Before:** User message pushed off screen as response appeared
**After:** User message stays visible at top of viewport

#### Implementation

New `scrollMessageToTop()` function added to both `chat.js` and `agent-runner.html`:

```javascript
function scrollMessageToTop(messageEl) {
    if (!messageEl || !chatMessages) return;
    const offsetTop = messageEl.offsetTop - 16;
    chatMessages.scrollTo({ top: offsetTop, behavior: 'smooth' });
}
```

#### Streaming Already Enabled

Both chat interfaces already support streaming responses via Server-Sent Events (SSE):

- **chat.html** → `/api/chat/stream`
- **agent-runner.html** → `/api/agents/:id/execute/stream`
