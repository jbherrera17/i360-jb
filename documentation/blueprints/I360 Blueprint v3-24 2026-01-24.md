## Executive Summary

Insight 360 is a **Values-Based AI Ecosystem** — a personal AI command center that aligns automated systems with organizational ethics. Version 3.24 delivers the **Agency Model** — enabling consulting agencies to manage multiple clients with white-label branding, client portals, and analytics dashboards.

**Core Philosophy:** *"Technology should augment human brilliance—not replace it."*

## Phase 41-43: Agency Model (v3.24)

### Feature 1: Organization Customization

Agencies can customize their platform appearance with branding options.

| Setting | Type | Description |
|---------|------|-------------|
| `primary_color` | Hex | Primary brand color |
| `secondary_color` | Hex | Secondary accent color |
| `logo_url` | URL | Organization logo |
| `favicon_url` | URL | Custom favicon |
| `welcome_message` | Text | Dashboard welcome text |
| `footer_text` | Text | Custom footer branding |

**API Endpoints:**
- `GET /api/org-customization/current` - Get org settings
- `PUT /api/org-customization` - Update branding
- `POST /api/org-customization/logo` - Upload logo

### Feature 2: Client Portal

Clients can access their dedicated portal with reports and AI interactions.

| Feature | Description |
|---------|-------------|
| **Report Viewer** | View shared reports from agency |
| **AI Chat** | Interact with agency-configured AI agents |
| **Dashboard** | Client-specific metrics and insights |
| **Document Access** | Shared files and deliverables |

**Routes:**
- `/client-portal.html` - Main client interface
- `/client-report-viewer.html` - Report viewing page

### Feature 3: Client User Management

Agencies can create and manage client user accounts.

| Action | Endpoint | Description |
|--------|----------|-------------|
| List clients | `GET /api/client-portal/clients` | View all client accounts |
| Create client | `POST /api/client-portal/clients` | Add new client user |
| Update client | `PUT /api/client-portal/clients/:id` | Modify client details |
| Delete client | `DELETE /api/client-portal/clients/:id` | Remove client access |

### Feature 4: Agency Analytics Dashboard

Comprehensive analytics across all clients.

| Metric | Description |
|--------|-------------|
| **Total Clients** | Active client count |
| **AI Interactions** | Total conversations across clients |
| **Reports Generated** | Content produced for clients |
| **Token Usage** | LLM consumption by client |
| **Active Users** | Client portal logins |

**API Endpoint:** `GET /api/agency-analytics/dashboard`
