## Phase 48: Platform Admin Enhancements (v3.29)

### What Was Completed

Phase 48 adds the ability for platform admins to create users directly and consolidates tier management to a single location.

### Feature 1: Platform Admin Create User

Platform admins can now create users directly from the Platform Admin dashboard:

| Field | Required | Description |
|-------|----------|-------------|
| Email | Yes | User's email address (auto-confirmed) |
| Password | Yes | Minimum 6 characters |
| Display Name | No | User's display name |
| Organization | No | Optionally assign to an organization |
| Role | No | Role in organization (consultant/admin/owner) |

**API Endpoint:**
- `POST /api/platform/users` - Creates user in Supabase Auth and users table

**Features:**
- Auto-confirms email (no verification required)
- Creates user record in both auth.users and public.users
- Optionally adds user to organization immediately
- Validates email format and password length
- Cleans up auth user if database insert fails

### Feature 2: Tier Management Consolidation

Removed duplicate tier editing from Platform Admin to establish a single source of truth:

| Before | After |
|--------|-------|
| Edit tier in Platform Admin modal | View-only tier display |
| Edit tier in Tier Setup page | **Single location** for tier editing |
| Confusion about which was authoritative | Clear "Configure Tiers" link |

**Changes:**
- Platform Admin Tiers tab now read-only
- Added "Configure Tiers" button linking to admin-tier-setup.html
- Replaced Edit button with Active/Inactive status badge
- Removed `editTier()` function from admin-platform.html
