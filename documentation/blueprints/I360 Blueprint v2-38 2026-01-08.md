# Insight 360 Blueprint v2.38

**Version:** 2.38
**Date:** January 8, 2026

## Executive Summary

Insight 360 is a **Values-Based AI Ecosystem** — a personal AI command center that aligns automated systems with organizational ethics. The platform combines multi-LLM capabilities with structured context assets to power intelligent agents that understand your business identity, voice, and values.

**Core Philosophy:** *"Technology should augment human brilliance—not replace it."*

### Workflow Documentation

#### Workflow User Guide

Comprehensive step-by-step instructions for using the workflow system:

- **Getting Started**: Accessing workflows from Execute 120
- **Running Workflows**: Step-by-step execution process
- **Step Types Explained**: user_input, agent_chat, review, output
- **Best Practices**: Tips for effective workflow usage
- **Troubleshooting**: Common issues and solutions

**File:** `documentation/guides/workflow-user-guide.md`

#### Workflow Technical Guide (New)

Developer-focused documentation covering:

- **Architecture Overview**: Step sequencing, variable interpolation
- **Step Configuration**: Schema and options per step type
- **API Reference**: Workflow CRUD, execution, step management
- **Workflow Engine Internals**: Context building, agent execution
- **Creating Custom Workflows**: Step-by-step guide
- **Testing & Debugging**: Validation and troubleshooting

**File:** `documentation/guides/workflow-technical-guide.md`
