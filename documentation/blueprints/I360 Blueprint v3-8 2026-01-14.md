## Phase 16: Reliability & Resilience (v2.33)

Implemented production-grade reliability patterns for graceful degradation and automatic recovery.

### Retry with Exponential Backoff

| Option | Default | Description |
|--------|---------|-------------|
| `maxRetries` | 3 | Maximum retry attempts |
| `initialDelayMs` | 1000 | Initial delay before first retry |
| `maxDelayMs` | 30000 | Maximum delay cap |
| `backoffMultiplier` | 2 | Exponential multiplier |
| `jitterFactor` | 0.1 | Random jitter (±10%) |

**Retryable Conditions:**
- Network errors: `ECONNRESET`, `ETIMEDOUT`, `ECONNREFUSED`, `EPIPE`, `ENOTFOUND`
- HTTP status codes: 408, 429, 500, 502, 503, 504
- Message patterns: Rate limit, Overloaded (Claude-specific)

### Circuit Breaker Pattern

| State | Description | Behavior |
|-------|-------------|----------|
| `CLOSED` | Normal operation | Requests pass through |
| `OPEN` | Service failing | Requests rejected immediately |
| `HALF_OPEN` | Testing recovery | Limited requests allowed |

**Configuration:**
- `failureThreshold`: 5 failures to open circuit
- `successThreshold`: 2 successes to close from half-open
- `timeout`: 30000ms before recovery attempt

**Health Endpoints:**
- `GET /api/health/circuits` - Circuit breaker statuses
- `POST /api/health/circuits/reset` - Reset all circuit breakers

### Timeout Wrapper & Fallback Handler

```javascript
const { withResilience } = require('./services/reliability');

const result = await withResilience(() => llmApiCall(), {
    operationName: 'llm-chat',
    timeout: 120000,
    circuitBreaker: 'anthropic',
    retryOptions: { maxRetries: 3, initialDelayMs: 1000 },
    fallback: { error: 'Service temporarily unavailable' }
});
```

**Files Created:**
- `server/services/reliability.js` - Retry, circuit breaker, timeout, fallback utilities
- `__tests__/unit/services/reliability.test.js` - 50 tests

## Phase 25: LLM Model Availability Check System (v3.6)

Implemented automated model availability checking for all configured LLM providers.

### Database Schema

```sql
CREATE TABLE model_availability_checks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    provider TEXT NOT NULL,
    status TEXT NOT NULL CHECK (status IN ('available', 'deprecated', 'unavailable', 'auth_error', 'rate_limited')),
    error_message TEXT,
    response_time_ms INTEGER,
    checked_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE model_check_config (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    schedule_time TIME DEFAULT '06:00:00',
    timezone TEXT DEFAULT 'America/New_York',
    is_enabled BOOLEAN DEFAULT true,
    last_run_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Status Types

| Status | Description |
|--------|-------------|
| `available` | Model responding correctly |
| `deprecated` | Model deprecated by provider |
| `unavailable` | Model not responding |
| `auth_error` | Authentication failed |
| `rate_limited` | Rate limit exceeded |

### API Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/model-availability/status` | Get latest status for all providers |
| POST | `/api/model-availability/check` | Trigger manual check |
| GET | `/api/model-availability/history` | Get check history |
| GET | `/api/model-availability/config` | Get scheduler config |
| PUT | `/api/model-availability/config` | Update scheduler config |

**Files Created:**

```

|                 MODAL RESIZE SYSTEM                               |

```

### Resize Handle Configuration

| Handle | Position | Cursor | Behavior |
|--------|----------|--------|----------|
| `top` | top: -4px, left/right: 16px | ns-resize | Height increases up |
| `bottom` | bottom: -4px, left/right: 16px | ns-resize | Height increases down |
| `left` | left: -4px, top/bottom: 16px | ew-resize | Width increases left |
| `right` | right: -4px, top/bottom: 16px | ew-resize | Width increases right |
| `top-left` | top: -8px, left: -8px | nwse-resize | Diagonal resize NW |
| `top-right` | top: -8px, right: -8px | nesw-resize | Diagonal resize NE |
| `bottom-left` | bottom: -8px, left: -8px | nesw-resize | Diagonal resize SW |
| `bottom-right` | bottom: -8px, right: -8px | nwse-resize | Diagonal resize SE |

### Key Fixes

1. **CSS Override Conflicts** - Added `!important` declarations for consistent behavior
2. **Handle Overlap with Header** - Positioned handles outside modal boundary
3. **Y-Axis Cursor Drift** - Store bottom edge for anchoring during resize
4. **Stale Handles in DOM** - Remove existing handles before adding new set
