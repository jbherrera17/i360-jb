## Admin Conversation Viewing Details

### UI Components

```
+----------------------------------+
| Conversation History             |
+----------------------------------+
| [x] Show all conversations       |  <-- Admin toggle
| [Organization Filter v]          |  <-- Org dropdown
+----------------------------------+
| Conv Title            [OrgName]  |  <-- Org badge
| User Name             Mon, Feb 7 |  <-- User + date
+----------------------------------+
```

### API Endpoints Used

| Endpoint | Purpose |
|----------|---------|
| `GET /api/platform/admin/verify` | Verify platform admin status |
| `GET /api/platform/organizations` | Load organizations for filter |
| `GET /api/conversations/admin/all?org_id=X` | Get all conversations with org filter |
| `GET /api/conversations/admin/:id` | Get single conversation as admin |
| `DELETE /api/platform/organizations/:id` | Delete organization (platform admin only) |

### Data Flow

1. On page load, `checkPlatformAdmin()` verifies admin status
2. If admin, filter controls are displayed and orgs are loaded
3. Toggle "Show all conversations" switches between user/admin endpoints
4. Org filter narrows results to specific organization
5. Conversation list shows user info and org badges in admin mode
