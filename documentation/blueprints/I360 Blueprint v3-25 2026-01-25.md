## Phase 44: Enterprise Multi-Tenancy (v3.25)

### Feature 1: Subscription Tier System

Four-tier subscription system with resource limits and feature gates.

| Tier | Members | Clients | Agents | Workflows | Key Features |
|------|---------|---------|--------|-----------|--------------|
| **Starter** | 3 | 0 | 5 | 3 | Basic modules only |
| **Business** | 10 | 0 | 25 | 15 | +Align120, Research Studio, TL |
| **Enterprise** | 100 | 0 | 100 | 50 | +SSO, Priority Support |
| **Agency** | 50 | 100 | 200 | 100 | +White-label, Client Portal |

**Database Table:** `subscription_tiers`

### Feature 2: Module Access Control

Module-based feature access controlled by subscription tier and business role.

| Module | Starter | Business | Enterprise | Agency | Min Role |
|--------|---------|----------|------------|--------|----------|
| Dashboard, Higgins, Agents | ✓ | ✓ | ✓ | ✓ | IC |
| Briefing, Context Assets | ✓ | ✓ | ✓ | ✓ | IC |
| Align120, Strategy, Execute120 | - | ✓ | ✓ | ✓ | - |
| Research Studio, Thought Leadership | - | ✓ | ✓ | ✓ | - |
| Workflows | - | ✓ | ✓ | ✓ | Manager |
| Agency Dashboard, Customization | - | - | - | ✓ | Director |
| Governance Dashboard | - | - | ✓ | ✓ | Director |

**Database Tables:** `platform_modules`, `org_module_access`, `role_module_access`

**Helper Functions:**
- `can_access_module(user_id, module_id, org_id)` - Check module access
- `get_user_modules(user_id, org_id)` - Get accessible modules list
- `check_org_limits(org_id, resource_type)` - Verify resource limits

### Feature 3: Platform Administration

Synergi super-admins can manage all organizations, tiers, and modules from a central dashboard.

| Feature | Description |
|---------|-------------|
| **Organization Overview** | View all organizations across the platform |
| **Tier Configuration** | Edit limits and features per subscription tier |
| **Platform Admins** | Manage super_admin, admin, support roles |
| **Module Management** | Enable/disable modules globally or per-org |
| **Usage Statistics** | Cross-platform metrics and health monitoring |

**API Endpoints:**
- `GET /api/platform/config` - Platform settings
- `GET/PUT /api/platform/tiers` - Manage tiers
- `GET/PUT /api/platform/modules` - Manage modules
- `GET/POST/DELETE /api/platform/admins` - Platform admins
- `GET /api/platform/organizations` - All orgs (admin view)

### Feature 4: Unified User Management

Single interface to manage users across all contexts: Platform, Agency Teams, and Client Portal.

| Context | Table | Auth Model |
|---------|-------|------------|
| Platform Admins | `platform_admins` | Password |
| Organization Members | `organization_members` | Password |
| Client Portal Users | `client_users` | Magic Link |

**UI Features:**
- Tab-based filtering (All | Platform | Agency Teams | Client Portal)
- Assignment badges showing all user memberships
- Inline assignment editing in user modal
- Context-aware add user flow

**API Endpoints:**
- `GET /api/users/unified` - Aggregated user data with all assignments
- `PUT /api/users/:id/assignments` - Manage platform admin, org memberships, client access

### Feature 5: Resource Limit Enforcement

All resource creation endpoints now check subscription tier limits.

| Resource | Limit Check | Affected Routes |
|----------|-------------|-----------------|
| Agents | `max_agents` | `POST /api/agents` |
| Workflows | `max_workflows` | `POST /api/workflows` |
| Skills | `max_skills` | `POST /api/skills` |
| Context Assets | `max_context_assets` | `POST /api/context` |
| Members | `max_members` | `POST /api/organization-members` |

**Middleware:** `server/middleware/moduleAccess.js`

### Feature 6: Dynamic Navigation

Navigation panel now builds dynamically based on user's accessible modules.

| Change | Description |
|--------|-------------|
| **Tools → Modules** | Renamed section for clarity |
| **Higgins First** | Moved to top of primary navigation |
| **Admin Items Relocated** | Team Members, Clients, Roles moved to administrator.html |
| **Agency Category** | Client Comparison moved under Agency |

## Architecture Overview

### Hierarchy Structure

```
Synergi (Platform Owner)
    └── Organizations (Clients/Agencies)
            ├── Departments
            │       └── Users (with business roles)
            └── Clients (for Agency tier only)
```

### Data Model

```
subscription_tiers
    └── organizations (subscription_tier FK)
            ├── organization_members
            ├── org_module_access
            └── clients
                    └── client_users

platform_admins (super-admin access)
platform_modules (module definitions)
role_module_access (role-to-module mapping)
```
