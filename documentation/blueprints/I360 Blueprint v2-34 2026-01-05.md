### Agent Introduction Messages

Agents can now have a custom introduction message that displays when users start a new chat, creating a more personalized experience.

#### Database Schema

```sql
ALTER TABLE agents ADD COLUMN introduction TEXT;
ALTER TABLE agents ADD COLUMN conversation_starters TEXT[] DEFAULT '{}';
```

#### Agent Edit Form

New fields added to the agent configuration modal:

| Field | Type | Description |
|-------|------|-------------|
| `introduction` | TEXT | Welcome message shown at chat start |
| `conversation_starters` | TEXT[] | Suggested prompts for users |

#### Example Usage

```json
{
  "name": "Strategy Advisor",
  "introduction": "Hello! I'm your Strategy Advisor. I specialize in helping you develop and refine your business strategy using proven frameworks.",
  "conversation_starters": [
    "Help me analyze my competitive landscape",
    "Review my current strategic priorities",
    "Identify growth opportunities in my market"
  ]
}
```

### Chat UX Improvements

#### User Message Visibility

When sending a message, the user's prompt now scrolls to the **top** of the chat viewport instead of the bottom. This keeps the user's question visible while the AI response streams below it.

**Before:** User message pushed off screen as response appeared
**After:** User message stays visible at top of viewport

#### Implementation

New `scrollMessageToTop()` function added to both `chat.js` and `agent-runner.html`:

```javascript
function scrollMessageToTop(messageEl) {
    if (!messageEl || !chatMessages) return;
    const offsetTop = messageEl.offsetTop - 16;
    chatMessages.scrollTo({ top: offsetTop, behavior: 'smooth' });
}
```

#### Streaming Already Enabled

Both chat interfaces already support streaming responses via Server-Sent Events (SSE):

- **chat.html** → `/api/chat/stream`
- **agent-runner.html** → `/api/agents/:id/execute/stream`
