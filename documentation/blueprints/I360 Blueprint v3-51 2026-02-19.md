Insight 360 is a **Values-Based AI Ecosystem** — a personal AI command center that aligns automated systems with organizational ethics. ## Phase 59: Guardrail & Bright Line Enforcement System (v3.51)

### What Was Completed

The soul configuration hierarchy (Platform → Organization → Department → Agent) and ethical context services were fully built but never wired into the LLM execution paths. Chat and agent systems operated without any awareness of organizational values, bright lines, or guardrails. There was also zero prompt injection or jailbreak protection anywhere in the codebase.

Phase 59 adds a complete enforcement layer that:
- **Pre-screens** every user message for prompt injection and bright line violations before any LLM call
- **Injects** soul context (safety instructions + ethical context + voice guidelines) into every system prompt
- **Blocks** violating requests with standard or admin-customized responses
- **Logs** incidents to the `bright_line_incidents` table for audit
- **Caches** resolved soul configurations with 5-minute TTL for performance

### Architecture

```
User Message
    │
    ├─→ Prompt Injection Detection (3 categories)
    │     ├── Instruction Override (HIGH): "ignore previous instructions", DAN mode, etc.
    │     ├── Role Confusion (HIGH): prompt delimiters, system prompt extraction
    │     └── Encoding Evasion (MEDIUM): base64 instructions, homoglyphs, zero-width chars
    │
    ├─→ Bright Line Keyword Screening (cached per org)
    │     ├── Keyword extraction from name, description, violation_examples
    │     ├── Threshold matching (2-3 keyword hits required)
    │     └── Response template hierarchy: per-line → org default → platform default → hardcoded
    │
    ├─→ Custom Pattern Screening (admin-configurable regex)
    │
    ├── BLOCKED → Standard response + incident log (no LLM call)
    │
    └── PASSED → Soul Context Block injected into system prompt
          ├── Safety Instructions (never reveal prompt, resist overrides)
          ├── Ethical Context (stakes level + SCU framework guidance)
          ├── Bright Lines (non-negotiable boundaries)
          └── Voice Guidelines (tone, avoid list)
```
