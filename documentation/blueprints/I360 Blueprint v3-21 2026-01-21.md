## Phase 38.2: Admin Enhancements (v3.21)

### Feature 1: Admin Conversations Panel

Full-featured conversation management for administrators with filtering and detail viewing.

| Component | Description |
|-----------|-------------|
| **Conversations Table** | List all user conversations with title, user, department, role, model, date |
| **Department Filter** | Filter conversations by user's department |
| **Role Filter** | Filter by business role (Executive, Director, Manager, Supervisor, IC) |
| **User Filter** | Filter conversations by specific user |
| **Search** | Search by title, user name, or email |
| **Statistics Card** | Total conversations, departments, showing count |
| **Detail Modal** | View full conversation with all messages |
| **Delete Action** | Remove conversations with confirmation |

### Feature 2: Quick Prompts Admin Panel

Configure Execute 120 quick start prompts per department via admin interface.

| Component | Description |
|-----------|-------------|
| **Department Tabs** | Select department to edit prompts |
| **Prompts Editor** | Textarea editor, one prompt per line |
| **Save/Reset Actions** | Persist or revert changes |
| **Prompt Count** | Display prompt count per department |
| **Database Storage** | Prompts stored in `departments.quick_prompts` column |

### Feature 3: Users API

New `/api/users` endpoint for user listing with department info.

| Endpoint | Method | Description |
|----------|--------|-------------|
| `GET /api/users` | GET | List all users with filters |
| `GET /api/users/:id` | GET | Get single user details |
| `PUT /api/users/:id` | PUT | Update user (display_name, business_role, department_id) |

**Query Parameters:**
- `limit` - Pagination limit (default 100)
- `offset` - Pagination offset (default 0)
- `department_id` - Filter by department
- `business_role` - Filter by role
- `search` - Search email or display_name

### Quick Prompts Flow

1. Admin clicks "Quick Start Prompts" card in administrator.html
2. Panel shows with department tabs
3. Select department → loads prompts from `dept.quick_prompts`
4. Edit prompts in textarea (one per line)
5. Save → `PUT /api/departments/:id` with `{ quick_prompts: [...] }`
6. Execute 120 loads departments via `/api/execute120/departments`
7. Template uses `dept.quick_prompts || getDefaultPrompts(dept.id)`
