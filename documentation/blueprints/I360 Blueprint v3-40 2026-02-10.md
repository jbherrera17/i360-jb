### Technical Notes

- **Soul Config DB Trigger Race Condition:** The `calculate_soul_completeness` trigger queries the OLD row in a BEFORE trigger, making completeness always one update behind. Resolved by issuing a dummy update after data changes to force recalculation.
- **Agent-Department Junction Table:** Agents use `department_agents` many-to-many junction table, not a direct `department_id` column. Total 214 junction entries for 112 agents (some agents serve multiple departments).
