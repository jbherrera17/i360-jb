## Phase 37: Execute 120 User Profile Personalization (v3.19)

### Feature 1: Auto-Select User's Department

Execute 120 now automatically selects the user's department based on their profile.

| Behavior | Description |
|----------|-------------|
| **On Load** | Fetches user profile via `/api/execute120/my-profile` |
| **Department Match** | Auto-selects user's assigned department |
| **Fallback** | Falls back to localStorage or first department if no assignment |
| **Manual Override** | Users can still manually select other departments |

**API Endpoint:** `GET /api/execute120/my-profile`

```json
{
  "success": true,
  "data": {
    "user": {
      "id": "uuid",
      "department_id": "uuid",
      "business_role": "manager",
      "department": { "id", "name", "slug", "icon", "color" },
      "role_info": { "id", "name", "level", "icon" }
    },
    "isExecutive": false,
    "showStrategyCards": false
  }
}
```

### Feature 2: Role-Based Content Filtering

Content is now filtered based on user's business role level (IC → Executive).

| Role Level | Level Number | Content Access |
|------------|--------------|----------------|
| Individual Contributor | 1 | IC-level content only |
| Supervisor | 2 | IC + Supervisor content |
| Manager | 3 | IC + Supervisor + Manager content |
| Director | 4 | IC through Director content |
| Executive | 5 | All content + Strategy Overview |

**Database Tables:**

```sql
-- Workflow role restrictions
CREATE TABLE workflow_roles (
    workflow_id UUID REFERENCES workflows(id),
    role_level TEXT REFERENCES business_role_levels(id),
    permission TEXT DEFAULT 'execute'
);

-- Agent role restrictions
CREATE TABLE agent_roles (
    agent_id UUID REFERENCES agents(id),
    role_level TEXT REFERENCES business_role_levels(id)
);

-- Context asset role restrictions
CREATE TABLE context_asset_roles (
    asset_id UUID REFERENCES context_assets(id),
    role_level TEXT REFERENCES business_role_levels(id)
);
```

### Feature 3: Personalized Cards API

New consolidated endpoint returns all dashboard cards filtered by department and role.

**API Endpoint:** `GET /api/execute120/my-cards`

| Card | Department Filter | Role Filter |
|------|------------------|-------------|
| Context Assets | User's dept or global | By role level |
| Agents | User's dept | By role level |
| Actions | User's dept | None |
| Workflows | User's dept or global | By role level |
| Daily Briefing | User's dept | None |
| Strategy Overview | N/A | Executive/Director only |

**Response:**
```json
{
  "success": true,
  "data": {
    "contextAssets": [...],
    "agents": [...],
    "actions": [...],
    "workflows": [...],
    "briefing": {...},
    "strategyOverview": {...}  // Only for executives
  }
}
```
