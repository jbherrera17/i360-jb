## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, and agency capabilities. Version 3.27 completes **Phase 45 Per-User Resource Access Control** and **Phase 46 Module Management & Admin Reorganization**.

## Access Control Layers

Version 3.27 implements a comprehensive three-layer access control system:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Tier** | Organization's subscription tier | Module access |
| **2. Module** | can_access_module() RPC | Feature routes |
| **3. Visibility** | private/team/org/public | Resource filtering |
