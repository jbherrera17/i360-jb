## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.56 delivers **Phase 60: Social Media Publishing via Postiz Integration** — multi-platform social media publishing to 8 platforms (Twitter, LinkedIn, Instagram, YouTube, Facebook, TikTok, Pinterest, Threads) with per-platform content adaptation, usage-based pricing, and multi-tenant isolation.

## Access Control Layers

Version 3.56 maintains the 6-layer access control with guardrail enforcement fully wired:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/invited/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **1c. Invitation** | Email invite → accept (PKCE or legacy) → set password → activate | New user onboarding |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** + social_posts and social_channels resource checks | Module access |
| **2b. Tier UI** | **Admin page hides agency-only elements for non-agency orgs** | UI visibility |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **6. Ethical** | Soul config bright lines + guardrails + prompt injection detection + enforcement service | AI responses |
