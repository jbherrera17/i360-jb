## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.48 delivers **Phase 57: Module Add-on Pricing, Agent Introductions & Soul Config CRUD** — enabling per-module add-on purchasing beyond tier bundles, populating all 112 agents with introductions and conversation starters, adding full CRUD to the soul configuration UI, and creating a public pricing API.

## Access Control Layers

Version 3.48 adds add-on purchase bypass to the tier layer:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **6. Ethical** | Soul config bright lines + guardrails | AI responses |
