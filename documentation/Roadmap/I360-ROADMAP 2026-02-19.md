## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.51 delivers **Phase 59: Guardrail & Bright Line Enforcement** — wiring the soul configuration system into every LLM execution path with prompt injection detection, bright line keyword screening, admin-customizable response templates, soul context injection into system prompts, and styled guardrail block rendering in the chat UI.

## What's New in v3.51

### Phase 59: Guardrail & Bright Line Enforcement System

| Component | Description | Impact |
|-----------|-------------|--------|
| **Guardrail enforcement service** | New `guardrailEnforcementService.js` — pre-screens messages for prompt injection and bright line violations with 5-min cached soul config resolution | Every LLM call is now values-aware |
| **Prompt injection detection** | 3 categories: instruction override, role confusion, encoding evasion — blocks jailbreak attempts before reaching the LLM | Security protection for all AI interactions |
| **Bright line screening** | Keyword matching against cached bright lines with configurable block/warn severity | Automatic enforcement of non-negotiable boundaries |
| **Soul context injection** | Safety instructions + ethical context + voice guidelines injected into every system prompt | LLMs operate within organizational values |
| **Admin response templates** | Per-bright-line custom responses, org-level defaults, platform defaults with hierarchical fallback | Customizable enforcement messaging |
| **SSE guardrail events** | New `guardrail_blocked` event type in streaming protocol | Chat UI renders styled shield containers |
| **Response defaults editor** | New section in Guardrails tab for editing default enforcement messages | Admin control over response language |
| **Cache invalidation** | `publishSoulConfig()` invalidates enforcement cache immediately | Config changes take effect instantly |
| **DB migration** | `response_defaults` JSONB column, incident tracking columns, performance index | Audit trail for all enforcement events |

## Access Control Layers

Version 3.51 maintains the 6-layer access control with guardrail enforcement fully wired:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/invited/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **1c. Invitation** | Email invite → accept → set password → activate | New user onboarding |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **6. Ethical** | Soul config bright lines + guardrails + **prompt injection detection + enforcement service** | AI responses |

## Soul Configuration Hierarchy

```
Platform (Synergi AI) — 100% Complete
├── Immutable: Platform Bright Lines (6), Security, SCU Lenses (6)
├── Identity: Visionary Pragmatist archetype
├── Values: 6 with meaning + behaviors (full CRUD in UI)
├── Guardrails: 4 categories (full CRUD in UI)
├── Voice: Professional tone, avoid list, personality 0.7
├── Domain: AI Business Intelligence, 6 products, 15 key terms
├── Stakeholders: 5 groups (clients, users, execs, dept heads, tech)
├── Escalation: 4-tier approval + triggers
├── Response Defaults: bright_line_blocked, guardrail_warning, escalation_notice
└── Organization
    ├── 3 org-level bright lines (full CRUD in UI, block/warn severity, custom responses)
    ├── Response Defaults: org-level override templates
    ├── Setup: 6 industry templates (SaaS, Healthcare, Legal, Finance, Nonprofit, Agency)
    └── Department/Client
        ├── Customizable: Value emphasis, Stakeholders
        └── Agent Instance
            └── Final computed soul = All levels merged + enforcement active
```
