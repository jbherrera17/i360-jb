## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, and external integrations. Version 3.31 introduces **Phase 49: External Integrations Framework** — a pluggable architecture for connecting to clients' existing systems and per-user productivity tools.

## Access Control Layers

Version 3.31 maintains the comprehensive four-layer access control system:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive | Login gate |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |

**New:** Integration add-ons gated by tier (Business → productivity, Enterprise → client systems, Enterprise Plus → custom).
