## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, and external integrations. Version 3.33 delivers **Phase 50b: Role-Based Resource Assignment** — connecting business roles and departments to all resource types (agents, skills, actions, workflows) so Execute 120 delivers personalized, role-appropriate experiences. Also adds platform admin impersonation ("Act As").

## Access Control Layers

Version 3.33 extends to a comprehensive **five-layer** access control system:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive | Login gate |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |

**New in v3.33:** Layer 5 ensures Execute 120 shows only role-appropriate and department-relevant agents, skills, actions, and workflows.
