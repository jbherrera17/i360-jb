## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.61 delivers **Phase 62: Open Brain MCP Integration** — connecting i360 to the Open Brain knowledge base via MCP Streamable HTTP transport, with a backend service layer, REST API wrapper, automatic Higgins context injection, a three-tab Capture/Browse/Templates UI, and a platform-admin-only DB module restriction ensuring the Open Brain page is exclusively accessible to `jb@synergiai.io`.

## What's New in v3.61

### Phase 62: Open Brain MCP Integration

| Component | Description | Impact |
|-----------|-------------|--------|
| **MCP client service** | `openBrainService.js` implements MCP Streamable HTTP transport (JSON-RPC 2.0 + SSE) connecting to Open Brain Supabase Edge Function; auth via `?key=` query param | i360 can read and write to Open Brain knowledge base |
| **REST API wrapper** | 5 endpoints at `/api/open-brain/`: status, capture, search, thoughts, stats | Standard HTTP interface to Open Brain for frontend and future integrations |
| **Higgins context injection** | Both regular and streaming chat endpoints search Open Brain for thoughts matching the user's message and inject them into the system prompt | Higgins automatically knows what's in Open Brain — no manual lookup needed |
| **Open Brain UI** | Three-tab page: Capture (textarea + Ctrl+Enter + recent list), Browse (semantic search + type/days filters + thought cards), Templates (5 capture patterns with examples and rationale) | Platform admin can add, search, and browse thoughts directly in i360 |
| **Floating chat modal** | FAB button → modal overlay with Search/Capture mode toggle | Quick capture/search without switching tabs |
| **platform_admin_only column** | New `BOOLEAN` column on `platform_modules`; `can_access_module()` rewritten to enforce it after the platform admin bypass | Fine-grained module restriction independent of tier or org role |
| **Open Brain module** | `open_brain` inserted into `platform_modules` with `nav_group = 'admin'`, `display_order = 63`, `platform_admin_only = TRUE` | Module appears in admin nav exclusively for platform admins |
| **Platform admin seed** | `jb@synergiai.io` inserted into `platform_admins` as `super_admin` via email lookup, idempotent | Ensures correct access regardless of deployment order |

## Access Control Layers

Version 3.61 maintains the 6-layer access control with guardrail enforcement fully wired, and adds a new module-level gating mechanism:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/invited/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **1c. Invitation** | Email invite → accept (PKCE or legacy) → set password → activate | New user onboarding |
| **2. Tier** | Organization's subscription tier **OR active add-on purchase** + social_posts and social_channels resource checks | Module access |
| **2b. Tier UI** | Admin page hides agency-only elements for non-agency orgs | UI visibility |
| **3. Module** | can_access_module() RPC — **now enforces platform_admin_only flag** | Feature routes |
| **3b. Platform Admin Only** | **platform_admin_only column on platform_modules — denies all non-platform-admins** | Open Brain + future restricted modules |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **5b. Favorites** | user_favorites table for per-user pinning across 5 entity types | Personal curation |
| **5c. Hidden Items** | user_hidden_items table for per-user dismiss across 5 entity types | Personal curation |
| **6. Ethical** | Soul config bright lines + guardrails + prompt injection detection + enforcement service | AI responses |
