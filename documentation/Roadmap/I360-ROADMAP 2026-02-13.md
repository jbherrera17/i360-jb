## Executive Summary

Insight 360 is a **full-service enterprise SaaS platform** enabling multi-tenant organizations with subscription tiers, module-based feature access, per-user resource visibility, complete user lifecycle management, agency capabilities, external integrations, a comprehensive **Human Values Definition System**, and **fully connected platform data** with org-scoped dashboards. Version 3.47 delivers **Phase 55-56: Agency Tier Split, Branding Expansion & Usage Nudges** — splitting the agency tier into 3 graduated tiers with upgrade paths, adding a full org branding panel with tier-locked white-label sections, introducing usage nudge warnings/blocks across resource pages, creating a runtime BrandingService for white-label injection, and redesigning the public pricing page with Synergi branding.

## Access Control Layers

Version 3.35+ adds an ethical evaluation layer:

| Layer | Check | Applied To |
|-------|-------|------------|
| **1. Account Status** | active/suspended/inactive + input validation | Login gate |
| **1b. Token Auth** | JWT required in production, HttpOnly cookies | All API routes |
| **2. Tier** | Organization's subscription tier | Module access |
| **3. Module** | can_access_module() RPC | Feature routes |
| **4. Visibility** | private/team/org/public | Resource filtering |
| **5. Role+Department** | business_role_levels + departments | Resource personalization |
| **6. Ethical** | Soul config bright lines + guardrails | AI responses |
