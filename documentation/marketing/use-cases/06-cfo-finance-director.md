# CFO / Finance Director Use Cases

**Department:** Finance
**Role Level:** C-Suite / Director
**Persona Reference:** Analytical Alex

---

## Role Overview

### North Star
"Every dollar must return multiples while protecting downside risk"

### Key Metrics
- Payback period ≤ 18 months
- IRR ≥ 25%
- OpEx down 8%

---

## Job Description & Responsibilities

| # | Responsibility | Description |
|---|----------------|-------------|
| 1 | **Financial Planning** | Lead FP&A and long-range planning |
| 2 | **Capital Allocation** | Optimize investment decisions and capital structure |
| 3 | **Risk Management** | Identify and mitigate financial and operational risks |
| 4 | **Board & Investor Relations** | Present financial performance and strategy |
| 5 | **Cash Management** | Ensure liquidity and treasury optimization |

---

## Pain Points

| Pain Point | Description | Business Impact |
|------------|-------------|-----------------|
| **ROI Quantification** | Hard to measure returns on intangible investments | Underinvestment in growth, missed opportunities |
| **Forecast Volatility** | Macro uncertainty makes planning hard | Reactive decisions, missed targets |
| **Data Quality** | Numbers from multiple sources don't align | Analysis paralysis, trust issues |
| **Compliance Burden** | Increasing regulatory requirements | Resource drain, distraction |
| **AI Cost Control** | New AI tools with unclear ROI | Budget concerns, adoption hesitation |

## Use Cases with Insight 360

### 1. Board Financial Summary
**Goal:** Synthesize financial data into board-ready narrative

**Workflow:**
1. Gather quarterly financial data
2. Identify key variances and drivers
3. Use **Meeting Prep** for board presentation structure
4. Use **Writing Coach** for narrative clarity

**Agents Used:** Meeting Prep, Writing Coach
**Gap Identified:** Financial Narrative Agent for finance-specific storytelling

---

### 2. Investment Analysis
**Goal:** Analyze potential investments with risk assessment

**Workflow:**
1. Define investment parameters and assumptions
2. Use **First Principles Thinker** for analysis framework
3. Use **Risk Sentinel** for risk identification
4. Develop recommendation with sensitivity analysis

**Agents Used:** First Principles Thinker, Risk Sentinel
**Gap Identified:** Investment Analyst Agent for structured analysis

---

### 3. Budget Scenario Modeling
**Goal:** Compare different budget allocation scenarios

**Workflow:**
1. Define scenario parameters
2. Input key assumptions and variables
3. Use **Research Assistant** for analysis
4. Compare outcomes and trade-offs

**Agents Used:** Research Assistant
**Gap Identified:** Budget Scenario Agent for modeling

---

### 4. Variance Analysis
**Goal:** Explain budget vs. actual variances

**Workflow:**
1. Identify significant variances
2. Gather context from department leaders
3. Use **Research Assistant** for synthesis
4. Generate executive summary of drivers

**Agents Used:** Research Assistant
**Gap Identified:** Variance Analyst Agent for automated explanation

---

### 5. Risk Assessment
**Goal:** Identify and quantify financial risks

**Workflow:**
1. Define risk categories to assess
2. Use **Risk Sentinel** for identification
3. Quantify potential impact
4. Develop mitigation strategies

**Agents Used:** Risk Sentinel
**Coverage:** Fully covered

---

### 6. Vendor ROI Analysis
**Goal:** Evaluate vendor spend vs. value delivered

**Workflow:**
1. Gather vendor costs and usage data
2. Define value metrics
3. Use **Research Assistant** for analysis
4. Make renewal/renegotiation recommendations

**Agents Used:** Research Assistant
**Gap Identified:** Vendor ROI Agent for systematic evaluation

---

### 7. Cash Flow Forecasting
**Goal:** Project cash positions under various scenarios

**Workflow:**
1. Define forecast period and assumptions
2. Input known cash flows
3. Use **Research Assistant** for scenario modeling
4. Identify potential cash gaps

**Agents Used:** Research Assistant
**Gap Identified:** Cash Flow Forecaster for treasury management

## Quick Start Prompts

### Board Summary
```
Prepare a board financial summary for Q4:
Revenue: $[X] vs. plan $[Y]
EBITDA: $[X] vs. plan $[Y]
Key variances: [LIST]

Provide:
- Executive narrative (2-3 paragraphs)
- Key drivers explanation
- Forward-looking commentary
- Questions the board may ask
```

### Investment Analysis
```
Analyze this investment opportunity:
Investment: [DESCRIPTION]
Amount: $[X]
Expected return: [METRICS]
Timeline: [PERIOD]

Evaluate:
- Strategic fit
- Financial returns (NPV, IRR, payback)
- Key risks and mitigations
- Recommendation with conditions
```

### Variance Analysis
```
Explain these budget variances:
Department: [DEPARTMENT]
Budget: $[X]
Actual: $[Y]
Variance: $[Z] ([%])

Provide:
- Root cause analysis
- One-time vs. recurring impact
- Forecast implications
- Corrective actions recommended
```

### Risk Assessment
```
Assess financial risks for [AREA/PROJECT]:
Context: [SITUATION]
Investment at stake: $[X]

Identify:
- Top 5 risks by impact
- Probability and severity
- Early warning indicators
- Mitigation strategies
```

### Vendor ROI
```
Evaluate ROI for [VENDOR]:
Annual spend: $[X]
Contract period: [DATES]
Primary use case: [USE CASE]

Analyze:
- Value delivered vs. cost
- Usage metrics
- Alternative options
- Renewal recommendation
```

## Financial Leadership Workflows

### Monthly Close Support
1. Review preliminary results
2. Identify material variances
3. Generate variance narratives
4. Prepare management reporting

### Quarterly Planning Cycle
1. Update assumptions and drivers
2. Run scenario models
3. Present options to leadership
4. Finalize operating plan

### Annual Budget Process
1. Gather department inputs
2. Consolidate and normalize
3. Run sensitivity analysis
4. Prepare board presentation
