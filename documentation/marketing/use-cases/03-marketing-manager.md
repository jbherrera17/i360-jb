# Marketing Manager / Content Strategist Use Cases

**Department:** Marketing
**Role Level:** Individual Contributor / Manager
**Persona Reference:** Brand-Builder Bella

---

## Role Overview

### Day in Life
Morning: Review campaign metrics and engagement data
Midday: Content brainstorm and editorial planning
Afternoon: Coordinate with agencies and martech sync
Evening: Record podcast clip or finalize content

| # | Responsibility | Description |
|---|----------------|-------------|
| 1 | **Campaign Execution** | Execute integrated campaign plans across channels |
| 2 | **Content Calendar** | Create and manage editorial calendar |
| 3 | **Agency Coordination** | Brief and manage agencies and freelancers |
| 4 | **Performance Reporting** | Report on campaign and content performance |
| 5 | **Martech Management** | Maintain and optimize marketing technology stack |

---

## Pain Points

| Pain Point | Description | Business Impact |
|------------|-------------|-----------------|
| **Content Fatigue** | Constant demand for fresh content | Burnout, quality decline |
| **Tool Overload** | Too many platforms, not integrated | Context switching, inefficiency |
| **Approval Bottlenecks** | Content stuck in review cycles | Missed deadlines, stale messaging |
| **Generic AI Output** | AI content sounds inauthentic | Brand erosion, audience disconnect |
| **Performance Pressure** | Prove ROI of every piece | Defensive marketing, short-term focus |

## Use Cases with Insight 360

### 1. Blog Post Generation
**Goal:** Draft thought leadership articles with brand voice

**Workflow:**
1. Define topic, audience, and key message
2. Load Voice DNA and ICP as context
3. Use **Writing Coach** for drafting and refinement
4. Use **Research Assistant** for supporting data/quotes

**Agents Used:** Writing Coach, Research Assistant
**Coverage:** Fully covered

---

### 2. Social Media Content
**Goal:** Generate platform-optimized social posts

**Workflow:**
1. Define platform (LinkedIn, Twitter, etc.)
2. Input key message or content to repurpose
3. Use **Writing Coach** with platform-specific instructions

**Agents Used:** Writing Coach
**Gap Identified:** Social Media Agent for platform optimization

---

### 3. Email Sequence Writing
**Goal:** Create nurture and campaign email sequences

**Workflow:**
1. Define sequence goals and recipient persona
2. Outline sequence stages (welcome, nurture, conversion)
3. Use **Writing Coach** for each email draft

**Agents Used:** Writing Coach
**Gap Identified:** Email Sequence Agent for sequence architecture

---

### 4. Landing Page Copy
**Goal:** Write conversion-focused landing page content

**Workflow:**
1. Define offer, audience, and desired action
2. Load conversion copywriting best practices
3. Use **Writing Coach** for persuasive copy

**Agents Used:** Writing Coach
**Gap Identified:** Conversion Copy Agent for specialized landing pages

---

### 5. Content Repurposing
**Goal:** Transform long-form content into multiple formats

**Workflow:**
1. Input long-form content (article, webinar, etc.)
2. Define target formats (social, email, slides)
3. Use **Writing Coach** to atomize content

**Agents Used:** Writing Coach
**Gap Identified:** Content Atomizer Agent for systematic repurposing

---

### 6. SEO Optimization
**Goal:** Optimize content for search while maintaining quality

**Workflow:**
1. Input target keywords and content
2. Use **Research Assistant** for keyword context
3. Use **Writing Coach** for SEO-friendly rewrites

**Agents Used:** Research Assistant, Writing Coach
**Gap Identified:** SEO Content Agent for search optimization

---

### 7. A/B Test Ideation
**Goal:** Generate test hypotheses for copy and creative

**Workflow:**
1. Define element to test (headline, CTA, image)
2. Use **First Principles Thinker** for hypothesis generation
3. Create test variants

**Agents Used:** First Principles Thinker
**Coverage:** Partially covered

## Quick Start Prompts

### Blog Post
```
Write a blog post on [TOPIC] for [AUDIENCE]:
- Key message: [MAIN POINT]
- Tone: [e.g., educational, conversational]
- Length: [word count]
- Include: supporting data, actionable takeaways
```

### Social Media
```
Create 5 LinkedIn posts from this content:
[PASTE CONTENT]
Requirements:
- Mix of formats (text, carousel hooks, questions)
- Maintain brand voice
- Include CTAs
```

### Email Sequence
```
Create a 5-email nurture sequence for [AUDIENCE]:
Goal: [CONVERSION GOAL]
Emails:
1. Welcome/value proposition
2. Pain point agitation
3. Solution education
4. Social proof
5. Offer/CTA
```

### Landing Page
```
Write landing page copy for [OFFER]:
Audience: [TARGET PERSONA]
Main benefit: [KEY VALUE PROP]
Sections needed:
- Hero headline and subhead
- 3 benefit bullets
- Social proof section
- CTA with urgency
```

### Content Repurposing
```
Repurpose this article into:
[PASTE ARTICLE]
- 3 LinkedIn posts
- 1 email newsletter
- 5 Twitter threads
- 1 slide deck outline (10 slides)
```

## Workflow Templates

### Weekly Content Planning
1. Review last week's performance metrics
2. Identify top-performing themes
3. Use **Research Assistant** for trending topics
4. Generate content briefs with **Writing Coach**
5. Schedule in content calendar

### Campaign Launch Checklist
- [ ] Campaign brief reviewed
- [ ] All assets drafted with brand voice
- [ ] Landing page copy finalized
- [ ] Email sequence complete
- [ ] Social posts scheduled
- [ ] Tracking parameters set
