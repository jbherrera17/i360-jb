# Finance Manager / Analyst Use Cases

**Department:** Finance
**Role Level:** Individual Contributor / Manager
**Persona Reference:** Analytical Alex (junior version)

---

## Role Overview

### Day in Life
Morning: Account reconciliations and data validation
Midday: Budget tracking and variance analysis
Afternoon: Report generation and formatting
Evening: Ad-hoc analysis requests and documentation

---

## Job Description & Responsibilities

| # | Responsibility | Description |
|---|----------------|-------------|
| 1 | **Financial Reporting** | Prepare and distribute financial reports |
| 2 | **Budget Tracking** | Monitor spending against budget |
| 3 | **Month/Quarter Close** | Support close process and reconciliations |
| 4 | **Ad-hoc Analysis** | Respond to analysis requests from stakeholders |
| 5 | **Process Documentation** | Document policies and procedures |

---

## Pain Points

| Pain Point | Description | Business Impact |
|------------|-------------|-----------------|
| **Manual Reconciliation** | Tedious, error-prone matching | Time waste, error risk |
| **Report Formatting** | Same reports, different formats | Rework, inconsistency |
| **Ad-hoc Request Overload** | Constant firefighting | No time for strategic work |
| **Data Hunting** | Information scattered across systems | Slow analysis, frustration |
| **Excel Dependency** | Complex models hard to maintain | Key person risk, errors |

## Use Cases with Insight 360

### 1. Report Narrative Generation
**Goal:** Write explanatory text for financial reports

**Workflow:**
1. Gather data and key metrics
2. Identify notable trends and variances
3. Use **Writing Coach** for clear narrative
4. Ensure consistency with prior reports

**Agents Used:** Writing Coach
**Gap Identified:** Financial Writer Agent for specialized finance language

---

### 2. Data Synthesis
**Goal:** Combine data from multiple sources into analysis

**Workflow:**
1. Define analysis objective
2. Gather data from various sources
3. Use **Research Assistant** for synthesis
4. Format for stakeholder presentation

**Agents Used:** Research Assistant
**Coverage:** Partially covered

---

### 3. Policy Documentation
**Goal:** Document financial policies and procedures

**Workflow:**
1. Interview process owners
2. Map current workflow
3. Use **Writing Coach** for clear documentation
4. Format for policy library

**Agents Used:** Writing Coach
**Coverage:** Fully covered

---

### 4. Audit Preparation
**Goal:** Organize and document audit support materials

**Workflow:**
1. Understand audit requirements
2. Gather supporting documentation
3. Use **Research Assistant** for organization
4. Prepare summary and index

**Agents Used:** Research Assistant
**Gap Identified:** Audit Prep Agent for systematic preparation

---

### 5. Process Improvement
**Goal:** Identify inefficiencies in finance workflows

**Workflow:**
1. Document current state process
2. Identify pain points and bottlenecks
3. Use **First Principles Thinker** for improvement ideas
4. Propose solutions with impact analysis

**Agents Used:** First Principles Thinker
**Coverage:** Partially covered

## Quick Start Prompts

### Report Narrative
```
Write narrative for monthly financial report:
Revenue: $[X] ([+/-]% vs. plan)
Expenses: $[X] ([+/-]% vs. plan)
Key variances:
1. [VARIANCE 1]
2. [VARIANCE 2]

Provide:
- 2-3 paragraph executive summary
- Bullet points on key drivers
- Forward-looking statement
```

### Data Synthesis
```
Synthesize data for [ANALYSIS]:
Sources:
1. [SOURCE 1]: [KEY DATA]
2. [SOURCE 2]: [KEY DATA]
3. [SOURCE 3]: [KEY DATA]

Objective: [WHAT YOU'RE TRYING TO UNDERSTAND]
Output: [FORMAT NEEDED]
```

### Policy Documentation
```
Document this financial policy:
Policy name: [NAME]
Purpose: [WHY THIS EXISTS]
Current process: [DESCRIPTION]
Key stakeholders: [ROLES]

Include:
- Policy statement
- Scope and applicability
- Procedures and steps
- Exceptions and approvals
- Related policies
```

### Audit Prep
```
Prepare audit documentation for [AREA]:
Audit period: [DATES]
Auditor requests: [LIST]
Available documentation: [LIST]

Provide:
- Document index
- Gap analysis
- Supporting narrative
- Recommended additional documentation
```

### Process Improvement
```
Analyze this finance process for improvement:
Process: [NAME]
Current steps: [LIST]
Time required: [DURATION]
Pain points: [LIST]

Identify:
- Bottlenecks and inefficiencies
- Automation opportunities
- Quick wins vs. major changes
- Implementation recommendations
```

## Finance Analyst Workflows

### Daily Checklist
1. Review overnight data feeds
2. Complete routine reconciliations
3. Flag exceptions for investigation
4. Update tracking dashboards

### Monthly Close Checklist
- [ ] Complete all account reconciliations
- [ ] Clear reconciling items
- [ ] Generate department reports
- [ ] Review variances with budget owners
- [ ] Prepare close package

### Quarterly Reporting
1. Gather department data
2. Validate against GL
3. Generate variance narratives
4. Format for executive review
5. Prepare board materials

## Tips for Working with Insight 360

### Best Practices
- Always provide context about the financial period and comparisons
- Include both the numbers and what story they tell
- Reference prior reports for consistency
- Be specific about the audience and format needed

### Common Patterns
- Use **Writing Coach** for report narratives
- Use **Research Assistant** for data synthesis
- Use **First Principles Thinker** for process analysis
