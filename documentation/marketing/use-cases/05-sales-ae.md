# Sales Director / Account Executive Use Cases

**Department:** Sales
**Role Level:** Individual Contributor / Manager
**Persona Reference:** Results-Driven Ryan

---

## Role Overview

### Day in Life
Morning: Pipeline stand-up and CRM updates
Midday: Discovery calls and deal strategy sessions
Afternoon: Executive alignment and forecast review
Evening: Prospect dinner or networking event

---

## Job Description & Responsibilities

| # | Responsibility | Description |
|---|----------------|-------------|
| 1 | **Quota Achievement** | Close deals and hit individual/team quota |
| 2 | **Pipeline Management** | Build and manage healthy pipeline |
| 3 | **Relationship Building** | Develop trusted relationships with buyers |
| 4 | **Buying Committee Navigation** | Map and influence all stakeholders |
| 5 | **Collaboration** | Partner with Solutions/SE team on technical validation |

---

## Pain Points

| Pain Point | Description | Business Impact |
|------------|-------------|-----------------|
| **CRM Data Entry** | Time spent logging vs. selling | Lost selling time, data quality issues |
| **Proposal Creation** | Manual, time-consuming proposals | Slow deal velocity, inconsistent quality |
| **Stakeholder Mapping** | Hard to track all buying influences | Blind spots, unexpected blockers |
| **Objection Handling** | Same objections, inconsistent responses | Lost deals, confidence issues |
| **Follow-up Discipline** | Too many balls in the air | Dropped deals, missed timing |

## Use Cases with Insight 360

### 1. Proposal Generation
**Goal:** Create customized proposals from templates + prospect context

**Workflow:**
1. Gather prospect requirements and pain points
2. Select appropriate proposal template
3. Use **Writing Coach** to customize sections
4. Review for value alignment

**Agents Used:** Writing Coach
**Gap Identified:** Proposal Generator Agent for faster customization

---

### 2. Email Follow-up Sequences
**Goal:** Draft personalized follow-up emails

**Workflow:**
1. Define follow-up context (post-call, post-demo, etc.)
2. Reference previous conversation points
3. Use **Writing Coach** for personalized drafts

**Agents Used:** Writing Coach
**Coverage:** Fully covered

---

### 3. Meeting Preparation
**Goal:** Research prospect company and attendees

**Workflow:**
1. Input company name and attendee list
2. Use **Meeting Prep** for comprehensive research
3. Enable web search for current news
4. Generate talking points and questions

**Agents Used:** Meeting Prep
**Coverage:** Fully covered

---

### 4. Objection Response
**Goal:** Get recommended responses to common objections

**Workflow:**
1. Document the specific objection
2. Provide context about the deal
3. Use **Strategic Advisor** for response strategy
4. Reference competitive positioning

**Agents Used:** Strategic Advisor
**Gap Identified:** Objection Handler Agent for instant responses

---

### 5. Call Debrief
**Goal:** Summarize calls and identify next actions

**Workflow:**
1. Record or note call highlights
2. Use **Research Assistant** for synthesis
3. Extract action items and commitments
4. Update CRM with key points

**Agents Used:** Research Assistant
**Gap Identified:** Call Summary Agent for quick debriefs

---

### 6. Discovery Questions
**Goal:** Generate tailored discovery questions by persona

**Workflow:**
1. Identify prospect persona (CFO, CTO, etc.)
2. Load ICP context for that persona
3. Use **First Principles Thinker** for question generation
4. Customize for specific industry/company

**Agents Used:** First Principles Thinker
**Gap Identified:** Discovery Guide Agent for persona-specific questions

---

### 7. Value Proposition Customization
**Goal:** Tailor messaging to specific buyer personas

**Workflow:**
1. Identify primary pain points
2. Load relevant ICP and positioning
3. Use **Writing Coach** for customized messaging
4. Align with buyer's language and priorities

**Agents Used:** Writing Coach
**Coverage:** Partially covered

---

### 8. Account Plan Development
**Goal:** Create strategic account plans

**Workflow:**
1. Gather account history and opportunity data
2. Map stakeholders and influence
3. Use **Strategic Advisor** for strategy development
4. Define milestones and success metrics

**Agents Used:** Strategic Advisor
**Gap Identified:** Account Planning Agent for comprehensive plans

## Quick Start Prompts

### Proposal Generation
```
Create a proposal for [COMPANY]:
Industry: [INDUSTRY]
Size: [EMPLOYEES/REVENUE]
Primary pain points:
1. [PAIN 1]
2. [PAIN 2]
3. [PAIN 3]

Include:
- Executive summary
- Solution overview mapped to pain points
- Timeline and investment
- Why us vs. alternatives
```

### Meeting Prep
```
Prepare me for a meeting with [COMPANY]:
Attendees: [NAMES AND TITLES]
Meeting type: [DISCOVERY/DEMO/NEGOTIATION]
Current stage: [PIPELINE STAGE]

Provide:
- Company background and recent news
- Attendee LinkedIn insights
- Likely priorities by role
- Questions to ask
- Landmines to avoid
```

### Objection Handling
```
Help me respond to this objection:
Objection: "[EXACT OBJECTION]"
Context: [DEAL SITUATION]
Competitor mentioned: [IF ANY]

Provide:
- Acknowledge and reframe
- Data points to counter
- Questions to redirect
- Next step recommendation
```

### Discovery Questions
```
Generate discovery questions for:
Prospect role: [TITLE]
Industry: [INDUSTRY]
Known challenge: [CHALLENGE]

Provide:
- 5 open-ended discovery questions
- 3 impact/consequence questions
- 2 vision questions
- Red flags to listen for
```

### Follow-up Email
```
Write a follow-up email after my [CALL TYPE]:
Key discussion points:
1. [POINT 1]
2. [POINT 2]
Next steps discussed: [NEXT STEPS]
Timeline mentioned: [TIMELINE]

Tone: [PROFESSIONAL/CONSULTATIVE/URGENT]
```

### Account Plan
```
Create a strategic account plan for [COMPANY]:
Annual revenue potential: $[AMOUNT]
Current products: [PRODUCTS]
Key stakeholders:
- [NAME, ROLE, DISPOSITION]

Include:
- Account overview and opportunity
- Stakeholder map and strategy
- Competitive landscape
- 90-day action plan
- Success milestones
```

## Sales Productivity Workflows

### Pre-Call Routine (10 min)
1. **Meeting Prep** research on attendees
2. Review previous notes and context
3. Set specific call objectives
4. Prepare 3 key questions

### Post-Call Routine (5 min)
1. Quick debrief with **Research Assistant**
2. Capture next steps and commitments
3. Update CRM
4. Schedule follow-up

### Weekly Pipeline Review
1. Update all deal stages
2. Identify stalled deals
3. Use **Strategic Advisor** for stuck deals
4. Prioritize week's activities
