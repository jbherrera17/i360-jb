| # | Responsibility | Description |
|---|----------------|-------------|

| 5 | **Issue Resolution** | Troubleshoot operational problems |

---

## Pain Points

| Pain Point | Description | Business Impact |
|------------|-------------|-----------------|
| **Documentation Backlog** | Processes exist but aren't written down | Knowledge loss, inconsistency |
| **Stakeholder Alignment** | Different priorities across departments | Friction, delays |
| **Measurement Inconsistency** | Departments measure differently | Comparison difficulty, debates |
| **Tool Fragmentation** | Different tools for different teams | Integration pain, data silos |
| **Training Burden** | Constant onboarding of new hires | Time sink, quality variance |

## Use Cases with Insight 360

### 1. SOP Creation
**Goal:** Generate standard operating procedures

**Workflow:**
1. Observe and document current process
2. Interview process experts
3. Use **Writing Coach** for structured SOP
4. Include visuals and decision trees

**Agents Used:** Writing Coach
**Gap Identified:** SOP Generator Agent for standardized procedures

---

### 2. Training Material Development
**Goal:** Create training guides and checklists

**Workflow:**
1. Define training objectives
2. Map skills and knowledge required
3. Use **Writing Coach** for content creation
4. Include exercises and assessments

**Agents Used:** Writing Coach
**Gap Identified:** Training Content Agent for learning design

---

### 3. Root Cause Analysis
**Goal:** Analyze incidents to find root causes

**Workflow:**
1. Document the incident and impact
2. Gather facts and timeline
3. Use **First Principles Thinker** for analysis
4. Identify root cause and corrective actions

**Agents Used:** First Principles Thinker
**Coverage:** Partially covered

---

### 4. Meeting Facilitation Prep
**Goal:** Prepare agendas and discussion guides

**Workflow:**
1. Define meeting purpose and attendees
2. Gather relevant context and data
3. Use **Meeting Prep** for agenda and prep
4. Include decision points and desired outcomes

**Agents Used:** Meeting Prep
**Coverage:** Fully covered

---

### 5. Status Report Generation
**Goal:** Create weekly/monthly status updates

**Workflow:**
1. Gather progress data and metrics
2. Identify accomplishments and blockers
3. Use **Writing Coach** for clear reporting
4. Highlight key decisions needed

**Agents Used:** Writing Coach
**Coverage:** Fully covered

---

### 6. Process Mapping
**Goal:** Document as-is and to-be process flows

**Workflow:**
1. Observe current workflow
2. Interview stakeholders
3. Use **Research Assistant** for documentation
4. Create visual process maps

**Agents Used:** Research Assistant
**Gap Identified:** Process Mapper Agent for systematic documentation

## Quick Start Prompts

### SOP Creation
```
Create an SOP for:
Process name: [NAME]
Purpose: [WHY THIS EXISTS]
Owner: [ROLE]
Frequency: [DAILY/WEEKLY/AS-NEEDED]

Include:
- Purpose and scope
- Prerequisites and requirements
- Step-by-step instructions
- Screenshots/diagram placeholders
- Troubleshooting guide
- Revision history section
```

### Training Material
```
Create training material for:
Topic: [SUBJECT]
Audience: [NEW HIRES/EXISTING STAFF]
Duration: [TIME]
Objectives: [WHAT THEY'LL LEARN]

Include:
- Learning objectives
- Content sections with key points
- Practice exercises
- Assessment questions
- Quick reference guide
```

### Root Cause Analysis
```
Analyze this incident:
Incident: [DESCRIPTION]
Date/Time: [WHEN]
Impact: [WHAT WAS AFFECTED]
Initial observations: [WHAT WE KNOW]

Provide:
- Timeline of events
- 5 Whys analysis
- Contributing factors
- Root cause identification
- Corrective actions
- Preventive measures
```

### Meeting Prep
```
Prepare agenda for:
Meeting: [NAME/PURPOSE]
Attendees: [LIST]
Duration: [TIME]
Decisions needed: [LIST]

Include:
- Agenda with time allocations
- Pre-read materials needed
- Discussion questions
- Decision framework
- Follow-up tracking
```

### Status Report
```
Generate status report for:
Period: [WEEK/MONTH]
Projects: [LIST]
Key metrics: [LIST]

Include:
- Executive summary (3 bullets)
- Progress vs. plan
- Key accomplishments
- Blockers and risks
- Upcoming milestones
- Support needed
```

### Process Map
```
Document this process:
Process: [NAME]
Trigger: [WHAT STARTS IT]
End state: [DESIRED OUTCOME]
Key steps: [HIGH-LEVEL LIST]

Provide:
- Process overview
- Detailed steps with owners
- Decision points
- Handoffs between roles
- Inputs and outputs
- Key metrics
```

4. Document findings and recommendations

1. Review improvement backlog
2. Prioritize initiatives
3. Execute quick wins
4. Report on progress
